# 06 - DMX 活动监视器 (Activity Monitor)

> **所属模块**: SuperTools — DMX 活动监视器  
> **适用对象**: 灯光编程师、技术人员  
> **前置阅读**: [01 - DMX 网络配置](./01_DMX_Network_Configuration_zh.md)  
> **最后更新**: 2026-04-14

---

## 一、概述

**DMX 活动监视器** 是一个查看 SuperStage 内部 DMX 缓冲区的调试工具。它按 Universe 显示通道值快照，帮助你：

- **验证网络连接** — 确认是否成功收到控台发来的 DMX 信号
- **排查地址问题** — 检查特定通道的值是否正确
- **监控信号状态** — 观察 DMX 数据是否正在变化

---

## 二、打开活动监视器

活动监视器**内嵌在 DMX 配置面板的下方区域**。打开 DMX 配置面板即可看到。

具体步骤：
1. 点击编辑器**底部状态栏**的 **SuperDMX** 按钮
2. DMX 配置面板打开后，上方是输入/输出设置，**下方就是活动监视器**

---

## 三、界面布局

活动监视器的界面分为两个部分：

### 3.1 控制栏

位于监视器顶部，包含以下控件：

| 控件 | 说明 |
|------|------|
| **All Universes** 复选框 | 勾选后显示所有包含非零通道值的 Universe |
| **Universe** 数字输入框 | 当 All Universes 未勾选时，指定要监控的单个 Universe 编号，范围 1-512 |
| **Clear** 按钮 | 清除当前监控范围内的 DMX 缓冲区数据 |

**刷新率固定为每 0.1 秒一次**，不随引擎帧率变化——它看的是缓冲区快照，不是逐帧实时值。

一条数据都没收到时，面板会显示提示 `No DMX data yet. Check Input Enable and source.`

## 四、通道值显示方式

每个通道以一个固定高度的灰度块和数字值表示：

| 通道值 | 灰度块 | 数字 |
|--------|-----------|------|
| 0 | 黑色 | 0 |
| 1 - 127 | 深灰到中灰 | 当前通道值 |
| 128 - 254 | 中灰到浅灰 | 当前通道值 |
| 255 | 白色 | 255 |

**显示规则**：
- 通道值越大，灰度块越亮
- 灰度块高度固定，不表示数值高低
- 每个通道下方直接显示 0-255 的数值

## 五、监控模式

### 5.1 监控所有 Universe（All Universes = 开）

- 自动显示所有**包含非零通道值**的 Universe
- 每个 Universe 占据一行，上方标注 Universe 编号
- 当新的 Universe 收到数据时，自动添加显示行
- 适合快速总览所有 DMX 信号状态

### 5.2 监控单个 Universe（All Universes = 关）

- 仅查询指定编号的单个 Universe
- 在 **Universe** 数字输入框中输入要监控的 Universe 编号
- 如果该 Universe 当前全为 0，界面会显示无数据提示
- 适合集中调试特定 Universe 的通道

## 六、数据刷新

活动监视器**自动周期性刷新**，从 SuperDMX 子系统读取最新的通道数据快照。

| 特性 | 说明 |
|------|------|
| **刷新频率** | 约每 0.1 秒刷新一次 |
| **数据来源** | DMX 子系统的接收缓冲区 |
| **显示范围** | 默认显示 1-512 通道 |

> **注意**：监视器显示的是 SuperStage 内部缓冲区中的值，也就是协议输入和 Universe 偏移处理后的结果。它适合确认 SuperStage 是否收到数据，但不能替代控台或抓包工具的底层网络诊断。

---

## 七、Clear 按钮

点击 **Clear** 按钮会：

1. All Universes 开启时，清除所有 Universe 的缓冲区
2. All Universes 关闭时，只清除当前选中 Universe 的缓冲区
3. 监视器显示变为空白
4. 如果场景灯具正在读取这些通道，显示状态会随缓冲区变为 0 而变化

**使用场景**：
- 测试前清空残留数据
- 确认灯具在全部通道为 0 时的行为
- 排查是否有"幽灵数据"（不再接收但仍残留的值）

> **注意**：Clear 只清除 SuperStage 内部的缓冲区。如果控台仍在发送信号，缓冲区会立即被新数据填充。

## 八、使用技巧

### 快速验证连接

1. 在控台中推高某个已知通道
2. 查看监视器中对应 Universe 和通道是否出现数值变化
3. 如果能看到变化，说明 SuperStage 已收到该通道的数据

### 定位通道地址

1. 在控台中只推一个灯具的 Dimmer 通道（值设为 255）
2. 在监视器中找到亮起的通道位置
3. 该位置就是灯具的实际 DMX 地址
4. 将灯具 Actor 的 Start Address 设为该位置（减去 Dimmer 的偏移）

### 检查通道冲突

1. 将 All Universes 设为开
2. 在控台中分别推不同灯具的通道
3. 观察是否有多个灯具的通道范围重叠
4. 如果同一段通道被多个灯具同时使用，需要检查 Patch 是否符合你的演出配置

## 九、常见问题

### Q: 监视器一片空白，什么都没有？
1. 检查 DMX 配置面板的「输入」是否已启用
2. 确认控台正在发送 Art-Net 或 sACN 信号，并且协议与输入设置一致
3. 确认本地 IP 选择正确
4. 检查防火墙设置

### Q: 只看到部分 Universe 的数据？
- 如果使用 All Universes 模式，只有**包含非零通道值**的 Universe 才会显示
- 如果某个 Universe 当前全为 0，该 Universe 不会出现在监视器中

### Q: 数据看起来不对（值不匹配）？
- 检查起始 Universe 偏移设置是否正确
- 可能存在 Universe 编号偏移，导致显示的 Universe 与控台对应关系错误

### Q: 柱状条在闪烁？
- 通道值正在变化或发送端正在持续刷新时，显示可能会变化
- 监视器本身约每 0.1 秒刷新一次；发送端实际刷新率取决于控台、协议和网络
