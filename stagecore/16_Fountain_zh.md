# 16 - 舞台喷泉

> **所属模块**: SuperCore ｜ **适用版本**: SuperStage 26H2.6 起
> **前置阅读**: [03 - DMX 灯具基础](03_DMX_Actor_Base_zh.md)

---

## 一、概述

**SuperFountain** 是 26H2.6 新增的舞台喷泉系统，可由 DMX 控制，与灯光共用同一套光学。

它由两个独立对象组成：

| 对象 | 性质 | 说明 |
| --- | --- | --- |
| **Super Fountain** | DMX 设备（14 通道） | 摇摆喷泉，喷头作为组件挂在它上面，带水下灯 |
| **Super Water Pool** | 舞美对象 | 水面与涟漪 |

> **两者互不依赖。** 只要水池就摆水池，不必先放喷泉；反过来，**喷泉设备本身不自带水面**——场景里没有水池对象时不会渲染水面。

在资产浏览器的 **SuperVFX** 分类下。

---

## 二、放置与基本设置

1. 从资产浏览器把 **Super Fountain** 拖进场景；
2. 需要水面时，另外放一个 **Super Water Pool** 并调整其位置与尺寸；
3. 按普通 DMX 灯具设置 **Universe**、**Start Address**、**ControlMode**，预留 14 个通道；
4. 要在属性面板手动预览时，把 `ControlMode` 设为 `Property`，然后调 Manual 那几项。

## 三、DMX 通道（14CH）

| 通道 | 功能 | 说明 |
| ---: | --- | --- |
| 1–2 | Pan | 16 位 |
| 3–4 | Tilt | 16 位 |
| 5 | Pan / Tilt 速度 | 最慢档为满速的 8%，与灯具同一口径 |
| 6 | 喷高 | |
| 7 | 发散角 | 映射到 0–20° |
| 8 | 水下灯亮度 | |
| 9 | 水下灯频闪 | 0–15 常亮；16–255 线性映射到 1–25 Hz |
| 10 | 水下灯红 | |
| 11 | 水下灯绿 | |
| 12 | 水下灯蓝 | |
| 13 | 水下灯白 | |
| 14 | 水下灯变焦 | 映射到 10–60° 外半角 |

> 发散角的物理上限是 45°，但喷泉超过 20° 已经是水雾，所以 DMX 行程只到 20°。

## 六、渲染分层

喷泉画面由五层构成：

| 层 | 内容 |
| --- | --- |
| 相干射流 | 解析弹道加破碎长度 |
| 破碎液滴 | GPU 粒子 |
| 掺气白水 | 射流破碎后的白色段 |
| 水池涟漪 | 高度场 |
| 水面渲染 | 解析求交，不生成网格 |

运动模糊快门默认跟随帧时长，帧率变化不会把水滴拉成连续划痕。

全部参数在细节面板与控制台变量两侧都可调。

## 七、常见问题

### 看不到水面

场景里有没有 **Super Water Pool**？喷泉设备本身不自带水面。

### 喷不高 / 喷太高

先看 Pump Pressure 与 Nozzle Diameter，这两项决定出流速度；DMX 的喷高通道是在这个物理基础上做的映射。

### 水下灯没颜色

确认 DMX 通道 10–13 有值，且 ControlMode 是 `DMX`。属性模式下 Manual 那几项只覆盖轴与频闪，颜色需要走 DMX 或在喷头参数里设 Light Color。

### 帧率下降明显

Sim Resolution（涟漪高度场分辨率）与水雾各项是主要开销来源。先把 Sim Resolution 降到 256 看看。

## 八、调优与诊断开关

喷泉有五十多个控制台变量，绝大多数是内部标定值，不该动。下面这些是实际会用到的，运行时改完立刻生效。

### 8.1 性能

| 变量 | 默认 | 作用 |
| --- | ---: | --- |
| `r.SuperFountain` | 1 | 喷泉总开关。0 关、1 开 |
| `r.SuperFountain.HalfRes` | 0 | 半分辨率水滴累积。1 = 半分辨率。水是全屏带宽大户，**这是掉帧时第一个该拨的开关** |
| `r.SuperFountain.MaxDrawDistance` | 30000 | 水滴绘制距离上限（cm，0 = 不限） |
| `r.SuperFountain.MaxParticles` | 2000000 | 粒子池容量。每个包裹 32 字节且双缓冲，200 万约合 128 MB 显存。**改这个会重建缓冲区** |
| `r.SuperFountain.MaxLights` | 256 | 单帧参与喷泉光照的锥光数上限（水下灯 + 外部灯）。超出的按注册顺序丢弃并告警。射程外的灯只读 16 字节，所以这个数可以比直觉大不少 |

### 8.2 观感

| 变量 | 默认 | 作用 |
| --- | ---: | --- |
| `r.SuperFountain.Ambient` | 0.3 | 环境光倍数，作用在世界天光强度上 |
| `r.SuperFountain.MaxRadiance` | 6.0 | 保色相的亮度上限（0 = 不限） |
| `r.SuperFountain.ExtinctionScale` | 1.0 | 光学厚度标定，调的是遮挡强度 |

### 8.3 诊断

| 变量 | 默认 | 作用 |
| --- | ---: | --- |
| `r.SuperFountain.Freeze` | 0 | 冻结模拟但继续绘制。1 = 冻结，用来看某一帧的粒子分布 |
| `r.SuperFountain.WaterDebug` | 0 | 水面调试。1 = 高度场热力图（蓝=凹 / 红=凸 / 灰平=撞击没登记上） |

## 九、安全边界

喷泉是**视觉模拟资产**。它不提供真实喷泉设备的水泵控制、电气控制、水处理、防触电保护或法规审批依据。真实水景必须由持证专业人员按当地法规实施。
