# Super Truss Tower 桁架塔 — 用户手册

## 1. 概述

**Super Truss Tower**（桁架塔）是 SuperStage 提供的程序化垂直桁架立柱生成工具。它模拟舞台灯光塔、音箱吊挂塔等垂直结构，支持载荷计算。

### 核心功能

- **垂直立柱结构** — 弦杆 + 斜撑 + 水平撑
- **底座板** — 接地面板，增大接触面积
- **顶部法兰** — 用于连接桁架网格或其他结构
- **欧拉临界载荷** — 简化的稳定性计算

### 适用场景

- 舞台灯光塔
- 音箱吊挂塔
- 桁架网格的垂直支撑
- 独立信号/旗帜塔

## 2. 主要参数

### 2.1 尺寸参数

| 参数 | 说明 |
|------|------|
| **TowerHeight** | 塔高 (cm) |
| **SectionType** | 截面类型：Box / Triangle / Flat |
| **TrussSize** | 规格：S290 / S400 / S520 |

### 2.2 构件可见性

| 参数 | 说明 |
|------|------|
| **bShowBasePlates** | 显示底座板 |
| **bShowTopFlange** | 显示顶部法兰 |
| **bShowDiagonals** | 显示斜撑 |
| **bShowHorizontalBraces** | 显示水平撑 |

### 2.3 载荷参数

| 参数 | 说明 |
|------|------|
| **TopLoad** | 顶部载荷 (kg) |

---

## 3. ISM 组件

| 组件 | 构件 |
|------|------|
| ChordISM | 弦杆（垂直主杆） |
| DiagonalISM | 斜撑 |
| HorizontalBraceISM | 水平撑 |
| BasePlateISM | 底座板 |
| TopFlangeISM | 顶部法兰 |

---

## 4. 统计信息

- **自重** — 塔身总重量
- **欧拉临界载荷** — 简化的屈曲稳定性计算

> ⚠️ 欧拉临界载荷为理论简化值，仅供参考，不可替代专业结构计算。

---

## 5. 使用提示

- 搭配 Super Truss Grid 使用时，塔顶法兰应与网格高度对齐
- Box 截面稳定性最好，适合高塔
- Triangle 截面适合轻型短塔
- 底座板在户外场景中可增大地面接触面积
