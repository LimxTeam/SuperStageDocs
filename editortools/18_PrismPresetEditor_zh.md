# 棱镜预设编辑器 用户手册

## 1. 功能范围

棱镜预设编辑器用于编辑 SuperStage 的 Prism Preset 资产。一个预设包含 3 个棱镜层，分别对应 Prism 1、Prism 2、Prism 3。每层由多个分光点组成，并带有整体缩放、位置缩放、旋转和偏移参数。

灯具能否显示这些棱镜效果，取决于灯具资产是否引用了该预设，以及灯具库的 Prism 槽位是否选择了对应的 Prism 层。

## 2. 创建和打开

1. 在 Content Browser 中右键创建 **Prism Preset** 资产。
2. 双击该资产打开编辑器。
3. 在编辑器中选择 Prism 1、Prism 2 或 Prism 3 进行编辑。

## 3. 画布操作

左侧画布显示当前层的分光点。

| 操作 | 说明 |
| --- | --- |
| 拖拽分光点 | 移动点的位置 |
| Ctrl + 点击 | 添加或取消选择 |
| 框选 | 选择多个点 |
| Delete | 删除选中的点 |
| Add Facet | 添加一个分光点 |
| Delete Selected | 删除当前选中的分光点 |

每层最多 48 个分光点。超过上限后无法继续添加。位置按整支灯归一化。

## 4. 层参数

| 参数 | 说明 |
| --- | --- |
| Enabled | 是否启用当前棱镜层 |
| Layer Name | 当前层名称 |
| Facet Size Scale | 整体调整所有分光点大小 |
| Position Scale | 整体调整分光点离中心的距离 |
| Global Rotation | 整体旋转当前层，单位为度 |
| Global Offset | 整体平移当前层 |

点自身也有 Position 和 Scale。Position 表示相对中心的 XY 偏移，Scale 表示该点的大小。

## 5. 排布方式（26H2.6 起为活参数）

排布不再是"点一下就填一批点"的一次性模板，而是**活参数**：面数、半径、面尺寸都是拨一下就重算的。

| 排布 | 说明 |
| --- | --- |
| **Manual (hand-placed)** | 逐面手填，分光点数组就是最终结果。既有资产的默认值，原样保留手填内容 |
| **Ring** | N 面等距环。最常见的形态 |
| **Ring + Centre** | N 面等距环加中心一面，中心那面通常更大更亮 |
| **Double Ring** | 内外双环，各自可设面数与半径 |
| **Line** | 一字排开（线性棱镜） |
| **Concentric Rings** | **任意圈数的同心环**，可选中心一面 |

**Concentric Rings** 是本版新增的，也是新做棱镜时的推荐选择：三圈、五圈、每圈面数各异、逐圈错相位都不用手摆。逐圈可设：

| 逐圈参数 | 范围 |
| --- | --- |
| Facet Count（面数） | 2–48 |
| Phase（相位） | 0–360° |
| Size Scale（尺寸倍率） | 0.05–4.0 |
| Position Scale（位置缩放） | 0–4.0 |
| Radius（半径） | 0–0.5 |
| Intensity（强度） | 0–4.0 |

Ring / Ring + Centre / Double Ring 都是同心环的特例，保留它们是因为既有资产按枚举名序列化着。

> 原先只有一排固定预设按钮，半径和面尺寸写死在按钮里，想把面数从 6 改成 8 等于推倒重来。

## 6. 预览和保存

编辑器会在资产修改后刷新当前预设数据。完成编辑后，使用 Unreal Editor 的保存功能保存资产。

Content Browser 中会为 Prism Preset 显示缩略图，便于辨认不同预设。

## 7. 导出位置贴图

编辑器提供位置贴图导出功能：

| 按钮 | 说明 |
| --- | --- |
| Export Current Layer | 导出当前启用层的位置贴图 |
| Export All Enabled Layers | 导出所有启用且包含分光点的层 |

导出的贴图用于需要直接引用位置贴图的材质流程。普通灯具使用 Prism Preset 资产时，通常不需要手动导出贴图。

## 8. 在灯具中使用

1. 在灯具资产或灯具配置中引用 Prism Preset。
2. 在灯具库 Prism 槽位里选择 Prism 1、Prism 2 或 Prism 3。
3. 控台或 DMX 数据触发对应槽位时，灯具会使用相应棱镜层。

## 9. 注意事项

- Prism 2 和 Prism 3 默认可能处于未启用状态，需要在编辑器中启用或套用模板。
- 空层不会产生可用的棱镜点。
- 切换排布方式会重算当前层的分光点；需要保留手填图案时，请保持排布为 **Manual**，或先复制资产。
- 最终视觉效果还受灯具材质、光束组件和灯具自身棱镜控制逻辑影响。
