# SuperStage NDI 输入配置 用户手册

> 适用版本：SuperStage 26H2.6 起 ｜ 所属模块：SuperNdi

## 功能定位

给每一路视频信号取一个场景可以依赖的名字，再把这个名字指向今天网络上的某个 NDI 源。

**打开方式**：SuperStage 工具栏中打开 NDI 配置面板。面板右上角有帮助按钮。

---

## 1. 为什么是两个名字

场景里的屏幕和投影引用的是**你自己取的输入名**——比如 `MainScreen` 或 `Camera1`。这个名字实际指向哪个 NDI 源，在这个面板里统一设置。

这一层间接就是它存在的全部意义：送信号的那台机器在每个场地叫的名字都不一样，每次重建场景是不可行的。在这里把名字重新指一下，所有用到它的地方就都跟着变了。

```text
场景里的屏幕  ──引用──>  输入名 "MainScreen"  ──映射──>  网络上的 NDI 源
（不用改）                （在本面板里改）              （每个场地都不同）
```

---

## 2. 配置一路输入

1. 在顶部输入框里打一个名字，点 **Add**。取一个描述**角色**的名字，不是描述机器的；
2. 点 **Refresh Sources** 扫描网络上正在广播的源。右侧的计数会显示找到了几个；
3. 在 **Configured Inputs** 列表里，展开你那一路输入旁边的下拉框，挑一个源。

改动**立即生效并被记住**，下次打开还在。

**Remove** 删掉一路输入；场景里还指着这个名字的对象将没有画面可显示。

---

## 3. 关于源列表

**这个列表是快照，不是实时视图。** 你上次刷新之后才打开的源不会出现在里面，需要再点一次 **Refresh Sources**。

发现过程在后台运行，所以编辑器不会卡住——扫描期间会显示进度提示。

选 **&lt;None&gt;** 可以在不删除输入的前提下把它解开，适合某一路信号临时离线、但你不想丢掉这份配置的情况。

---

## 4. 画面接不上时

| 现象 | 处理 |
| --- | --- |
| **一个源都找不到** | NDI 只能发现同一网络里的机器。确认发送端在同一子网、防火墙没有拦，再刷新一次 |
| **源在列表里，场景里却没有画面** | 确认输入名与场景里那块屏幕设的名字**完全一致**——任何一边打错字都是这个结果 |
| **本来好好的，突然断了** | 多半是发送端改了自己的源名。刷新后重新选一次 |

---

## 5. 支持的像素格式

| 格式 | 处理 |
| --- | --- |
| BGRA / BGRX | 直接接收 |
| UYVY / UYVA | 自动转换 |
| 其他 | 不支持 |

---

## 6. 使用注意

- NDI 运行库随插件分发，不需要单独安装 NDI 工具；
- NDI 依赖局域网发现与网络带宽；源由第三方软件产生，其行为不受本产品控制；
- NDI 能力的授权范围以官方定价页与订单为准。
