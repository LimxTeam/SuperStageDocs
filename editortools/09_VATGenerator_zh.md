# VAT 角色生成器 用户手册

> 适用版本：SuperStage 26H2.6 起

## 功能定位

把带动画的角色烘焙成纹理，用于超大规模人群。

面板右上角有帮助按钮。

---

## 1. 它产出什么

它把一个带动画的角色变成舞台场景可以**大量显示**的东西。动画不再逐骨骼播放，而是烘进纹理、由材质回放，所以同样一群人的开销只是普通骨骼动画角色的一小部分。

每生成一项产出三样东西：

| 产物 | 说明 |
| --- | --- |
| **VAT 网格** | 这个角色的静态网格 |
| **动画纹理** | 这一段动画对应的一对纹理（位置 + 法线） |
| **材质实例** | 纹理已经接好，开箱可用 |

把 VAT 网格拖进关卡、指定材质实例，动画就播起来了。生成的角色可以加进 [Super Crowd](../stageassets/12_SuperCrowd_zh.md) 的角色列表。

---

## 2. 建立列表

| 按钮 | 作用 |
| --- | --- |
| **Add Selected** | 把内容浏览器里当前选中的动画序列各加一行。角色网格会**自动**从动画自带的预览网格填入，多数时候只需要核对一下 |
| **Add Item** | 加一个空行，手工填 |
| **Clear** | 清空整个列表 |
| **Remove** | 只删这一行 |

每一行都需要**动画**和**角色网格**两样，而且两者必须属于**同一套骨骼**。不是的话，该行会在目标文件夹的位置显示原因，并在生成时被跳过。

---

## 3. 生成

点 **Generate VAT** 会先问结果放哪里。选好文件夹后，一切自动归档在它下面：**一个角色一个文件夹，里面一段动画一个文件夹**。选定文件夹之后，每一行会显示它将要写入的确切目标路径，动手之前可以先核对布局。

进度对话框跟踪整批任务，**随时可以取消**。取消之前已经完成的会保留；底部的汇总行会告诉你创建了几个、跳过了几个、失败了几个。

> 长动画与高密度网格最慢，因为工作量正比于**帧数 × 顶点数**。进度条按帧计量，所以走得是实速，不会一项一跳。

---

## 4. 重跑与复用

**生成可以安全重复。** 目标位置已经存在的东西会被原样保留并报告为"已存在"，不会重建——所以往一份已有的列表里加几段新动画再跑一遍，不用等旧的重做。

**同一个角色的多段动画共用一个 VAT 网格**：它只建一次，批次里每段动画都复用它。要强制重建，先在内容浏览器里删掉已有资产。

**失败的行会标红并写明原因。** 常见的两种是骨骼不匹配、以及名字不能用作资产名。改好那一行再跑一遍，已经成功的行会直接跳过。

---

## 5. 使用注意

- 生成的 VAT 角色是**静态网格 + 材质动画**，不参与骨骼动画系统，也不能在运行时切换动作；
- 一个角色的每段动作各占一对纹理，动作越多占用越大；
- 随包已经提供 13 个 VAT 角色（见 [Super Crowd](../stageassets/12_SuperCrowd_zh.md)），本工具用于加入项目自有的角色。
