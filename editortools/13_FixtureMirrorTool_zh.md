# SuperStage 镜像工具 用户手册

## 1. 功能范围

镜像工具把选中的一批 Actor 沿一个平面镜像复制到对侧。舞台布光几乎必然左右对称，手工摆另一半既慢又容易出错。

**源不限定为灯具。** 选区里的任何 Actor 都会被一起镜像 —— 镜像一整套对称机位时，桁架、舞美这些要跟着过去。灯具会重新发灯具编号、套 `型号名_编号` 命名；普通 Actor 不占灯具编号，只保证标签唯一（按源名称加序号）。

源 Actor 不会被移动或删除，镜像出来的是新的一批。

## 2. 打开方式

在编辑器左侧模式栏切换到 **SuperStage Edit Mode**，然后在模式工具栏中选择 **Mirror**。

使用前需要先在视口中选中一个或多个 Actor。

## 3. 基本流程

1. 在视口中选中要镜像的 Actor。
2. 打开 **Mirror**。
3. 选 **Plane Normal**（镜像平面的法线轴）与 **Plane Offset**（平面沿该轴的位置）。视口里会画出这个平面。
4. 需要时点 **Set Plane To Selection Center** 把平面挪到选区中心。
5. 检查预览。
6. 点击 **Create Fixtures** 创建，或点击 **Cancel** 丢弃预览并退出。

创建操作支持编辑器撤销：Ctrl+Z 会把镜像出来的这一批整体撤回，Ctrl+Y 可以再恢复。

## 4. 状态信息

| 字段 | 说明 |
| --- | --- |
| Status | 当前操作提示 |
| Source Actors | 当前作为镜像源的 Actor 数量 |
| Preview Count | 当前预览的数量 |

## 5. 镜像平面

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| Plane Normal | 镜像平面的法线轴。Y 表示沿舞台中线做左右镜像 | Y |
| Plane Offset (cm) | 平面沿法线轴的位置，世界坐标厘米 | 0 |

平面会以蓝色网格画在视口里，网格尺度跟着选区大小走。

落在平面上的 Actor（1 厘米容差内）会被跳过 —— 它的镜像就是它自己，只会得到一个重叠的副本。状态栏会写明跳过了几个。

## 6. 镜像出来的朝向是怎么算的

这一节解释工具的行为，避免误解。

**位置**对平面做反射，没有争议。

**朝向不是简单地"把变换镜像一下"。** 反射矩阵的行列式是 -1，直接套到 Actor 上等于给了一个负缩放，网格会翻面。而且现实中根本不存在"镜像版灯具" —— 你在另一侧挂的是同一款、同样挂法的灯，只是转了个方向。

工具的做法是：把光束轴和参考切向这一对反射过去，再重建成一个合法的右手旋转。结果是光束**对称地**指向对侧应该指的方向，而灯具自身的左右侧被对调 —— 这正是现实中"同一支灯挂到对面"的结果。**不需要、也不应该对 yoke（灯架）做任何特殊处理。**

## 7. DMX 分配

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| Assign DMX Addresses | 是否给镜像出来的灯顺排 Universe 与起始地址 | 开启 |

灯具编号（Fixture ID）无论开关如何都会给新灯分配，因为 Actor 标签里写着它。

**本工具不处理 Pan 反转。** 对称机位要跟着同一份编程动作，靠的是配接层的 Pan 反转标志 —— **几何上做不出来**，没有任何旋转能把"pan 反向"变出来。MVR 规范里这是每灯一个 `DMXInvertPan` 标志，控台（如 MA）也放在配接里。这件事请在控台或配接环节处理。

同理，gobo / 棱镜的转向也不镜像 —— 那是每个 cue 的编程选择（控台效果引擎里做相位镜像），不是灯具属性。

## 8. 创建结果

点击 **Create Fixtures** 后，工具会：

- 在一个事务内生成正式 Actor（因此整批可撤销）。
- 使用每个源 Actor 作为模板，保留它自己的配置。
- 给新建的灯具分配灯具编号，并按设置分配 DMX 地址；非灯具只做标签去重。
- 按设置放入 World Outliner 文件夹（留空时用 `MirroredFixtures`）。
- 选中新建的这一批。
- 关闭工具。

## 9. 注意事项

- 任何 Actor 都可以作为镜像源，包括普通静态网格体。只有 SuperStage DMX 灯具会参与发号与灯具命名。
- 预览态下按 Ctrl+S 保存关卡、启动 PIE 或切换到别的工具，都会**丢弃**预览而不是提交。提交只有 **Create Fixtures** 一个入口。
- 面板参数在同一次编辑器会话内会被记住；重启编辑器后回到默认值。
- 如果没有预览，请确认视口里确实选中了 Actor，并检查 Status 提示；也可能是所有 Actor 都落在了镜像平面上。
