# SuperStage 资产浏览器用户手册

> 适用版本：SuperStage 26H2.6 起（本版重做）

## 功能定位

资产浏览器用于按分类找到灯具、道具或特效，并把它放进场景。

**打开方式**：SuperStage 工具栏 → **SuperBrowser**。面板右上角有帮助按钮。

---

## 1. 界面

| 区域 | 说明 |
| --- | --- |
| 左侧分类树 | 缩小右侧显示范围，每行带该节点下的数量 |
| 搜索框 | 同时匹配型号、厂商与灯具类型 |
| 右侧瓦片视图 | 可放置的资产 |
| 右下角滑块 | 调整格子大小 |
| Refresh | 重新扫描 |

分类树结构：顶部是 **All**（钻进某个分类后靠它回到全部），下面是三个快捷行（All / Favorites / Recent），再往下是大分类，每个大分类下是有内容的厂商。

资产分五类：

| 分类 | 内容 |
| --- | --- |
| StageLight | 灯库，由 GDTF 导入 |
| StageModel | 舞美结构：桁架、脚手架、舞台面、看台、围栏、幕布、线槽、观众等 |
| SuperVFX | 特效设备：烟、火、雪、泡泡、彩带、烟花、喷泉、水池 |
| SuperLight | 自研灯具七个系列 |
| SuperStage | 舞台设备：屏幕、投影仪、激光、灯带、导播相机、升降与轨道机械、Madrix、白模等 |

---

## 2. 搜索

搜索框**同时匹配名称、厂商与灯具类型**，支持空格分词——多个词要全部命中，顺序不限。所以输入 `robe beam` 能找到 Robe 的光束灯。

搜索与分类树**协同工作**：可以先选一个厂商，再在它里面搜。

---

## 3. 收藏与最近使用

一场演出通常就那么几支灯反复摆。树顶的两行为此而设。

**Favorites（收藏）** 是你自己整理的列表：

- 右键格子 → **Add to favourites**，格子角上出现一颗星，在浏览器任何地方都能认出来；
- 已收藏的项，同一个菜单项变成 **Remove from favourites**；
- **收藏按用户保存**，不会随工程跟到别人那里。

**Recent（最近使用）** 自己填自己：拖出去或放置过的资产落到最前面，最新的在最上。不用维护，正在用的灯自己浮上来。

- 试过一次不想留：右键 → **Remove from recent**；
- 清空整个列表：右键树里的 **Recent** 行 → **Clear recent list**。收藏不受影响。

---

## 4. 放进场景

| 操作 | 说明 |
| --- | --- |
| **拖格子到视口** | 拖到想放的位置。常规做法 |
| **双击格子** | 直接丢进关卡，不用瞄。位置暂时不重要、或者接下来要用阵列工具摆的时候好用 |

> 灯具放进去时是**未配接**的。要它响应控台，先在 Patch 工具里给 Universe、地址和编号。

---

## 5. 替换场景里已有的灯

在关卡里选中一个或多个对象，然后在浏览器里**右键一个格子** → **Replace selected actor with this asset**。

- 菜单会写明当前选中了几个 Actor，动手前能看清规模；
- 每个选中项被换成你挑的那个，**保留位置、朝向与 DMX 模式**；
- 这是把整套灯从一个型号换成另一个型号的做法——比如场地给的型号和图纸上画的不是同一款——不必重新摆一遍。

> **配接不会跟着过来。** 换完的灯请重新配接。

---

## 6. 其他右键操作

| 操作 | 说明 |
| --- | --- |
| 放置 | 放进关卡 |
| 替换 | 见第 5 节 |
| 收藏 / 取消收藏 | 见第 3 节 |
| 在内容浏览器中定位 | 跳到该资产 |
| 打开灯具定义 | 直接进灯具编辑器 |

---

## 7. 格子信息

每个格子显示缩略图与名称。**悬停**显示完整型号、厂商、类型与 DMX 模式数。

---

## 8. 找不到东西时

| 现象 | 处理 |
| --- | --- |
| 刚加的资产没出现 | 列表通常自己更新；没更新就按 **Refresh** |
| 明知道存在的灯搜不到 | 先点 **All**——树里可能还选着某个分类或厂商，搜索只在当前范围内找 |
| 东西跑到 **Default** 分类下了 | 没设分类的资产都会落到这里。给它设一个分类，以后才找得到 |
| 刚打开时缩略图是空的 | 预览图在后台生成，第一次打开面板时会陆续填上 |

---

## 9. 使用注意

- 拖一支灯进场景**不会**把页面弹回 All、也不会把侧边栏分组折叠起来。点侧边栏空白处才会回到 All，这是预期行为；
- 列表随资产导入与删除自动更新，Refresh 是给编辑器外部发生变化的少数情况准备的。
