# SuperStage 批量 Patch 工具 用户手册

## 1. 概述

批量 Patch 工具（Super Patch Tool）用于为场景中选中的多个灯具批量分配 DMX 地址。它可以自动计算每个灯具的 Universe 和起始通道地址，支持预览、应用和撤销。

---

## 2. 打开方式

**主菜单路径**：工具栏 **SuperStage** 下拉菜单 → **SuperDMXTool** → **PatchTool**

## 4. 参数说明

### 4.1 起始参数

| 参数 | 说明 | 范围 | 默认值 |
|------|------|------|--------|
| **起始 Universe** | 第一个灯具分配到的 Universe 编号 | 1 - 512 | 1 |
| **起始地址** | 第一个灯具在该 Universe 中的起始通道地址 | 1 - 512 | 1 |
| **起始 Fixture ID** | 第一个灯具的 Fixture ID 编号，后续灯具自动递增 | 1 - 9999 | 1 |

### 4.2 地址分配规则

工具按照以下规则自动计算后续灯具的地址：

1. 从指定的起始 Universe 和起始地址开始
2. 每个灯具占用的通道数量由其灯库定义的通道跨度（Channel Span）决定
3. 当一个灯具分配完成后，下一个灯具的地址 = 当前地址 + 通道跨度
4. 如果地址超过 512（一个 Universe 的最大通道数），自动跳转到下一个 Universe 的第 1 通道
5. FixtureID 从**起始 Fixture ID** 开始自动递增分配，跳过场景中已被其他灯具占用的 ID（ID=1 作为默认值例外）

## 5. 灯具列表

### 5.1 列说明

| 列名 | 说明 |
|------|------|
| **灯具名称** | 灯具在场景中的标签名称 |
| **型号** | 灯具型号/类型名 |
| **Universe** | 分配后的 Universe 编号 |
| **起始地址** | 分配后的起始通道地址 |
| **通道数** | 该灯具占用的通道数量 |
| **FixtureID** | 分配的灯具编号 |

### 5.2 排序规则

灯具列表按照自然排序（Natural Sort）显示。例如：
- Light_1, Light_2, Light_3, ..., Light_10, Light_11
- 而不是：Light_1, Light_10, Light_11, ..., Light_2, Light_3

## 6. 面板控件

面板始终作用于**场景中当前选中**的灯具，并跟随选择变化实时重算方案——在视口或大纲里换一批灯，方案就跟着换。**没有单独的"预览"按钮**：列表里显示的一直是尚未写入的方案，按 **Apply** 才落到灯上。

| 控件 | 类型 | 作用 |
|------|------|------|
| **Start Universe** | 输入框 | 起始 Universe |
| **Start Address** | 输入框 | 起始地址 |
| **Start Fixture ID** | 输入框 | 起始灯具编号 |
| **SelectAllDevices** | 按钮 | 选中场景里所有灯具。从零开始配接时用 |
| **RenameID** | 勾选框 | 同时把选中灯具改名，使大纲里的名字与刚分到的编号一致。手工命过名又想保住名字，就取消勾选 |
| **Apply** | 按钮 | 把方案写进灯具 |
| **ClearPatch** | 按钮 | 把选中灯具重置到 Universe 1 / 地址 1。**灯具编号保持不动**——地址反正要重写，而编号是控台识别灯具的依据，不值得一起丢 |
| **Refresh** | 按钮 | 重新读一遍当前选择与场景。面板开着时别处新增或改动了灯具，用它同步 |

三个起始值在每次 Apply 之后会自动跳到下一个空位，所以整套灯配接下来就是**选一批、Apply、再选一批、Apply**，中间不用碰数字。

**Ctrl+Z 撤销整批**。

## 7. 使用流程

### 步骤 1：选择灯具

在 3D 视口中框选或逐个选中需要批量 Patch 的灯具。

### 步骤 2：打开批量 Patch 工具

通过主菜单打开工具面板。

### 步骤 3：设置起始参数

- 设置 **起始 Universe**（如第 1 个 Universe）
- 设置 **起始地址**（如从第 1 通道开始）

### 步骤 4：核对方案

- 列表里显示的就是尚未写入的方案，随选择实时更新，不需要另外点什么去生成；
- 面板开着时若在别处新增或改动过灯具，点 **Refresh** 重新读一遍；
- 看工具栏下面那行摘要——它写明这批有多少支要配接，**把鼠标停在上面**能看到具体会落在哪段 Universe、地址与灯具编号上。

> 摘要行**变成橙色**表示有灯具配接不了，Apply 会跳过它们、照常配其余的。停在摘要上能看到是哪几支、为什么：
> **Span>512** 表示这支灯需要的通道数超过一个 Universe 装得下，哪儿都放不下，检查它是不是选错了 DMX 模式；
> **Universe overflow** 表示这一批排到了最后一个 Universe 之外，起始值往前调，或者一次少配几支。
> 按 Apply 之前先看这行，别等配完才发现漏了一半。

### 步骤 5：应用

- 点 **Apply** 把地址写进灯具；
- 三个起始值会自动跳到下一个空位，接着选下一批直接再按 Apply 即可。

## 8. 下半部分的通道图

面板下半部分把每个 Universe 的 512 个槽位铺成格子（32 列 × 16 行），每支已配接的灯具画成一块彩色方块，盖住它占用的地址。想找一段可以插进去的空位、或者一处该修的重叠，看这里最快。

**用到的 Universe 全部纵向排列**，每块上面有一行 `Universe N` 标题，整体滚动查看——没有翻页控件。

### 8.1 直接在图上配接

这张图不只是看，也能直接改地址：

- **拖动一个灯具块**到新槽位就改它的地址；把它往下拖到另一个 Universe，就换到那个 Universe；
- 选中了一批灯时，**拖其中任意一支会带着整批一起走**，各自保持原有间距——原本跨两个 Universe 的，移完还是隔一个 Universe；
- **落点会压到别的灯身上时，方块变红并拒绝落下**。不会有东西被悄悄覆盖；挪到一段空位上，颜色就恢复。

### 8.2 从大纲直接拖灯进来

把灯具从世界大纲拖进这张图，它们会落在**你松手位置往后的第一段连续空通道**上，自动跳过已经配接的区段。

- 已经有编号的灯**保留原编号**，只有从没编过号的才会分到新号；
- 有灯放不下时，会提示有几支没放进去。

---

## 9. 撤销操作

应用操作支持 **Ctrl+Z 撤销**。如果发现分配有误，可以直接撤销恢复到之前的状态。

---

## 10. 注意事项

- 只有 SuperStage DMX 灯具（SuperDmxActorBase 的子类）会出现在列表中
- 普通的 UE 灯光或其他类型的 Actor 不会被识别
- 如果场景中没有选中任何灯具，列表将为空
- 通道跨度为 0 的灯具可能导致地址计算异常，请确保灯库配置正确
- 当灯具数量较多时，地址可能跨越多个 Universe，请确保你的 DMX 网络支持所需的 Universe 数量

---

## 11. 常见问题

| 问题 | 解决方法 |
|------|----------|
| 灯具列表为空 | 先在场景中选中灯具，再点击"刷新选择" |
| 预览显示的地址不对 | 检查起始 Universe 和起始地址设置是否正确 |
| 应用后灯具没响应控台 | 检查 DMX 配置面板中的输入设置是否匹配 |
| 某些灯具地址重叠 | 检查灯库中通道跨度配置是否正确 |
