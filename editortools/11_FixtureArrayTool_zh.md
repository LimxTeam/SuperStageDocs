# SuperStage 灯具阵列工具 用户手册

## 1. 功能范围

阵列工具用于把当前选中的一个或多个 Actor 复制成线性、网格或环形排列。工具会根据参数生成预览，确认后创建正式 Actor。

**源不限定为灯具。** 选区里的任何 Actor 都会被整组复制 —— 真实工作流就是「一段桁架带着上面挂的几支灯一起阵列」。灯具会重新发灯具编号、套 `型号名_编号` 命名；桁架、舞美这类普通 Actor 不占灯具编号，只保证标签唯一（按源名称加序号）。

源组不会被删除。创建时它会整组占据阵列中离**组形心**最近的那一格，其余格位才新建。这样源的 DMX 地址、灯具编号、名称、图层，以及 Sequencer 或 MA3 对它的绑定全部原样保留；最终摆出来的总数与「格位数 × 组内 Actor 数」一致。

> 线性阵列和环形阵列（勾选 Include Center 时）下，最近的一格通常就是源组原位，它不会移动；网格阵列开启 Center At Source 时，源组会整体挪到最近的格心。

## 2. 打开方式

在编辑器左侧模式栏切换到 **SuperStage Edit Mode**，然后在模式工具栏中选择 **Array**。

使用前需要先在视口中选中一个或多个 Actor。选区里的**第一个** Actor 是主源，它的朝向决定了阵列参考系 —— Spacing 向量、网格轴向都在这个参考系里解释。阵列的原点取选区各 Actor 位置的形心（只选一个时就是它自己的位置）。

## 3. 基本流程

1. 在视口中选中一个或多个 Actor（灯具、桁架、舞美都可以）。
2. 打开 **Array**。
3. 选择 **Array Type**：Linear、Grid 或 Radial。
4. 调整对应参数并检查预览。
5. 点击 **Create Fixtures** 创建正式灯具。
6. 需要退出但不创建时，点击 **Cancel** 或关闭当前工具。

创建操作支持编辑器撤销：按 Ctrl+Z 会把新建的灯具整体撤回、源灯具回到原位，Ctrl+Y 可以再恢复。

## 4. 状态信息

| 字段 | 说明 |
| --- | --- |
| Status | 当前操作提示 |
| Source Group | 源组：单选时是它的名称，多选时是「主源 + 还有几个」 |
| Preview Count | 当前预览的 Actor 数量（含源组占的那一格） |

## 5. 通用参数

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| Array Rotation | 整个阵列绕组形心叠加的旋转 | 0, 0, 0 |
| Item Rotation | 每份拷贝额外叠加的旋转（多选时绕该格位整体旋转，不是每个 Actor 各转各的） | 0, 0, 0 |
| Create Folder | 创建后是否放入 World Outliner 文件夹 | 开启 |
| Folder Name | 文件夹名称；留空时使用型号名加 `_Array` | 空 |
| Assign DMX Addresses | 是否给新建灯具顺排 Universe 与起始地址 | 开启 |

如果文件夹名已存在，工具会在名称后自动加序号。源灯具也会一并放进这个文件夹。

自动文件夹名取的是**型号名**而不是 Actor 类名：数据驱动灯具全部型号共用同一个类，用类名会得到谁都认不出的 `SuperFixtureActor_Array`。

## 6. Linear 线性阵列

线性阵列从组形心开始，按 **Spacing** 向量依次排列每一份拷贝。

| 参数 | 说明 | 范围/默认值 |
| --- | --- | --- |
| Count | 灯具数量 | 1-100，默认 5 |
| Spacing | 相邻灯具的三维间距，单位为厘米 | 默认 100, 0, 0 |

Spacing 会先受**主源**（选区第一个 Actor）的旋转影响，再叠加 Array Rotation。因此主源朝向会影响线性阵列方向。

## 7. Grid 网格阵列

网格阵列按 X/Y 数量生成二维排列。

| 参数 | 说明 | 范围/默认值 |
| --- | --- | --- |
| Count X | 第一方向数量 | 1-50，默认 3 |
| Count Y | 第二方向数量 | 1-50，默认 3 |
| Spacing X | 第一方向间距，单位为厘米 | 最小 1，默认 100 |
| Spacing Y | 第二方向间距，单位为厘米 | 最小 1，默认 100 |
| Plane | 网格平面的法线轴 | X、Y、Z，默认 Z |
| Center At Source | 是否以组形心作为网格中心 | 开启 |
| Honeycomb Offset | 奇数行沿第一方向的偏移比例 | 0-1，默认 0 |

Plane 为 Z 时，网格使用 XY 平面；Plane 为 Y 时，网格使用 XZ 平面；Plane 为 X 时，网格使用 YZ 平面。

## 8. Radial 环形阵列

环形阵列围绕组形心生成圆形或圆弧排列。

| 参数 | 说明 | 范围/默认值 |
| --- | --- | --- |
| Count | 圆周或圆弧上的灯具数量 | 2-100，默认 8 |
| Radius | 半径，单位为厘米 | 最小 10，默认 200 |
| Start Angle | 起始角度 | 0-360，默认 0 |
| End Angle | 结束角度 | 0-360，默认 360 |
| Rotation Axis | 环形所在平面的法线轴 | X、Y、Z，默认 Z |
| Orient To Center | 是否让灯具朝向中心 | 开启 |
| Include Center | 是否在中心额外放置一个灯具 | 关闭 |

当 Start Angle 到 End Angle 接近 360 度时，工具按完整圆处理，最后一个圆周点不会与第一个点重叠。不是完整圆时，起点和终点都会被包含在圆弧中。

开启 Orient To Center 时，灯具朝向由「它到圆心的方向」决定，并以环所在平面的法线作为参考上方向，因此整圈灯具的滚转是一致的。此时 Array Rotation 只影响位置——朝向已经是从旋转后的位置反推出来的，不再二次叠加。

## 9. DMX 分配

新建的灯具是源灯具的模板克隆，会连带复制源灯具的 Universe 与起始地址。**Assign DMX Addresses** 开启时（默认），工具会给新建灯具重新顺排地址：从全场已占用的最后一个槽位往后排，按每支灯的通道跨度推进，跨过 512 自动进位——口径与批量 Patch 工具一致。域号排到上限后剩余灯具会保留模板地址，并在输出日志里给出警告。

关闭该开关时只分配灯具编号，地址保持模板值（即整排同址），交给批量 Patch 工具统一处理。此时 Status 会提示 `DMX addresses left to Patch Tool`。

灯具编号（Fixture ID）无论开关如何都会给新建灯具分配，因为 Actor 标签里写着它，两者始终一致。源灯具保留自己原有的编号与地址，不会被改动。

## 10. 创建结果

点击 **Create Fixtures** 后，工具会：

- 在一个事务内生成正式 Actor（因此整批可撤销）。
- 使用每个源 Actor 作为模板，保留它自己的配置。
- 让源组就地占据离组形心最近的一格，其余格位新建。
- 给新建的**灯具**分配灯具编号，并按设置分配 DMX 地址；非灯具只做标签去重。
- 灯具按 `型号名_灯具编号` 命名；非灯具沿用源名称加序号。源组保留原名。
- 按设置放入 World Outliner 文件夹（源组也一并放进去）。
- 选中整批。
- 关闭工具。

## 11. 注意事项

- 任何 Actor 都可以作为源，包括普通静态网格体（桁架、舞美）和非 SuperStage 的灯光。只有 SuperStage DMX 灯具会参与发号与灯具命名。
- 创建大量 Actor 时，编辑器响应速度取决于 Actor 复杂度和当前关卡规模。调整参数时预览是就地移动而不是重建，因此拖动滑块比首次生成要轻。注意总量是「格位数 × 组内 Actor 数」，选一整段桁架做大网格会很快堆起来。
- 预览期间源组会被临时隐藏（它们那一格已经有预览了），退出工具或清除预览时逐个还原成你自己的隐藏状态。
- 预览态下按 Ctrl+S 保存关卡、启动 PIE 或切换到别的工具，都会**丢弃**预览而不是提交。提交只有 **Create Fixtures** 一个入口。
- 面板参数在同一次编辑器会话内会被记住；重启编辑器后回到默认值。
- 如果没有预览，请确认视口里确实选中了 Actor，并检查 Status 提示。
