# SuperStage 灯具阵列工具 用户手册

## 1. 功能范围

灯具阵列工具用于把当前选中的一个 SuperStage DMX 灯具复制成线性、网格或环形排列。工具会根据参数生成预览，确认后创建正式灯具。

创建完成后，原始源灯具会被删除，阵列中的第一个灯具会占用源灯具的位置或按当前阵列规则计算的位置。因此，使用前请确认源灯具已保存或可被替换。

## 2. 打开方式

在编辑器左侧模式栏切换到 **SuperStage Edit Mode**，然后在模式工具栏中选择 **Fixture Array Tool**。

使用前需要先在视口中选中一个 SuperStage DMX 灯具。如果选中了多个 Actor，工具会使用选区中第一个可用的 DMX 灯具。

## 3. 基本流程

1. 在视口中选中一个 SuperStage DMX 灯具。
2. 打开 **Fixture Array Tool**。
3. 选择 **Array Type**：Linear、Grid 或 Radial。
4. 调整对应参数并检查预览。
5. 点击 **Create Fixtures** 创建正式灯具。
6. 需要退出但不创建时，点击 **Done** 或关闭当前工具。

创建操作支持编辑器撤销。

## 4. 状态信息

| 字段 | 说明 |
| --- | --- |
| Status | 当前操作提示 |
| Source Fixture | 当前源灯具名称 |
| Preview Count | 当前预览中新建灯具的数量 |

## 5. 通用参数

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| Array Rotation | 整个阵列绕源灯具位置叠加的旋转 | 0, 0, 0 |
| Item Rotation | 每个灯具额外叠加的旋转 | 0, 0, 0 |
| Create Folder | 创建后是否放入 World Outliner 文件夹 | 开启 |
| Folder Name | 文件夹名称；留空时使用灯具类型名加 `_Array` | 空 |

如果文件夹名已存在，工具会在名称后自动加序号。

## 6. Linear 线性阵列

线性阵列从源灯具位置开始，按 **Spacing** 向量依次排列。

| 参数 | 说明 | 范围/默认值 |
| --- | --- | --- |
| Count | 灯具数量 | 1-100，默认 5 |
| Spacing | 相邻灯具的三维间距，单位为厘米 | 默认 100, 0, 0 |

Spacing 会先受源灯具旋转影响，再叠加 Array Rotation。因此源灯具朝向会影响线性阵列方向。

## 7. Grid 网格阵列

网格阵列按 X/Y 数量生成二维排列。

| 参数 | 说明 | 范围/默认值 |
| --- | --- | --- |
| Count X | 第一方向数量 | 1-50，默认 3 |
| Count Y | 第二方向数量 | 1-50，默认 3 |
| Spacing X | 第一方向间距，单位为厘米 | 最小 1，默认 100 |
| Spacing Y | 第二方向间距，单位为厘米 | 最小 1，默认 100 |
| Plane | 网格平面的法线轴 | X、Y、Z，默认 Z |
| Center At Source | 是否以源灯具位置作为网格中心 | 开启 |
| Honeycomb Offset | 奇数行沿第一方向的偏移比例 | 0-1，默认 0 |

Plane 为 Z 时，网格使用 XY 平面；Plane 为 Y 时，网格使用 XZ 平面；Plane 为 X 时，网格使用 YZ 平面。

## 8. Radial 环形阵列

环形阵列围绕源灯具位置生成圆形或圆弧排列。

| 参数 | 说明 | 范围/默认值 |
| --- | --- | --- |
| Count | 圆周或圆弧上的灯具数量 | 2-100，默认 8 |
| Radius | 半径，单位为厘米 | 最小 10，默认 200 |
| Start Angle | 起始角度 | 0-360，默认 0 |
| End Angle | 结束角度 | 0-360，默认 360 |
| Rotation Axis | 环形所在平面的法线轴 | X、Y、Z，默认 Z |
| Orient To Center | 是否让灯具朝向中心 | 开启 |
| Include Center | 是否在中心额外放置一个灯具 | 关闭 |

当 Start Angle 到 End Angle 接近 360 度时，工具按完整圆处理，最后一个圆周点不会与第一个点重叠。不是完整圆时，起点和终点都会被包含在圆弧中。

## 9. 创建结果

点击 **Create Fixtures** 后，工具会：

- 将当前预览灯具转为正式 Actor。
- 使用源灯具作为模板保留同类配置。
- 按灯具类型名和现有编号继续命名。
- 按设置放入 World Outliner 文件夹。
- 删除原始源灯具。
- 关闭工具。

创建后建议检查 DMX 地址。如果源灯具地址被复制到多个灯具上，可以使用批量 Patch 工具重新分配地址。

## 10. 注意事项

- 普通点光源、聚光灯等非 SuperStage DMX 灯具不能作为源灯具。
- 创建大量灯具时，编辑器响应速度取决于灯具复杂度和当前关卡规模。
- 预览只用于确认位置和旋转；最终 DMX 地址仍需要按项目规则检查。
- 如果没有预览，请确认已经选中 SuperStage DMX 灯具，并检查 Status 提示。
