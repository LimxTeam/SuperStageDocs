# SuperVolumetricBeamComponent（体积光束）

> 适用版本：SuperStage 26H2.6 起

体积光束是空中光柱的**默认后端**。随包灯库已全量迁移到它。

它与 [锥形光](10_SuperConeLightComponent_zh.md) 共用同一张阴影图集与同一套光学，所以光柱与地面光斑被同一批遮挡体一致地遮挡，颜色和角度也不会分家。

---

## 1. 参数

灯具定义的 **VolumetricBeamDefaults** 分组，全部是原生物理量，没有历史换算系数。

同一组参数在场景里选中光束组件后，也能在细节面板的 **B.BeamParameter** 分组下直接改，改完实时生效，方便调参对比。注意**灯具的 DMX 通道会覆写对应字段**——接了控台之后，被通道驱动的那几项（强度、Iris 等）以通道值为准。

| 参数 | 默认值 | 范围 | 说明 |
| --- | ---: | --- | --- |
| **Disable Beam** | 关 | — | 隐藏体积光束，仅保留光源和光斑。**不等同于删除灯具** |
| **Beam Occlusion** | 开 | — | 真实几何动态遮挡 |
| **Beam Intensity** | 1.0 | 0–10 | 光束强度乘数 |
| **Density** | 0.36 | 0.05–10 | 介质密度（雾气浓度乘数）。实测标定值——1.0 的浓度会把光束糊成实心棒，细节全埋掉 |
| **Haze Amount** | 0.6 | 0–1 | 雾气噪声强度，光束内流动雾气的可见程度 |
| **Haze Scale** | 1.3 | 0.01–10 | 雾气噪声尺度（1/米）。1.3 ≈ 亚米级絮团，实测最像真实舞台烟雾 |
| **Haze Speed** | 25 | 0–200 cm/s | 雾气漂移速度，0 = 静止。**26H2.6 新接出的参数**，此前流速被絮团大小绑死且慢到看不出在动 |
| **Lens Radius** | 8 | 0.5–100 cm | 光束起端半径。Iris 在此基准上向下缩放 |
| **Falloff** | 1.0 | 0–1 | 轴向衰减，0 = 无衰减、1 = 末端归零。配合 0.36 的低密度，满衰减给出的是自然沿程消散而不是硬截断 |
| **Edge Softness** | 1.0 | 0–1 | 边缘柔和度，1 = 最柔。真实雾中光束没有硬边 |
| **Near Fade** | 0 | 0–2000 cm | 近端淡入距离。0 = 灯口即满亮 |
| **Far Fade Fraction** | 0.12 | 0–1 | 远端淡出比例，占光束长度 |
| **Distance Fade End** | 0 | 0–500000 cm | 相机距离淡出终点。**0 = 不限距离，且默认必须是 0** |

> **关于 Distance Fade End**：它曾默认 80000（800 米），超出这个距离整条光束会在剔除阶段被丢掉，表现为"摄像机明明拍得到，光束却没了"。舞台预演不是开放世界，场景本来就不大，距离剔除只会制造这种莫名其妙的消失。要限距离得逐灯显式填。

## 2. 遮挡

启用 Beam Occlusion 的光束会拿到一个**阴影图集槽位**。每槽从灯具视角把锥内遮挡体光栅化成距离图，光束着色时按分段采样做梯形加权——切口平滑无硬棱角。遮挡体或光束移动时逐帧重建，天然全动态。

**槽位不按相机距离排队。** 候选只做一件事：剔掉屏幕外的。屏幕里看得见、亮着、想投影的灯都会进来，不会出现"离相机远就没影子"。

两种情况下仍然会没有阴影：**全局质量降到 Low** 时整段阴影跳过；灯的数量超过图集容量时超出的部分拿不到槽位（会打日志）。

遮挡体的发现依赖物理场景查询（QueryOnly 碰撞即可）。骨骼网格以胶囊代理投影。

---

## 3. 光学元件

图案（GOBO）、色轮、棱镜由锥形光那条着色器路径统一投射，光柱与光斑同源。

**图案边缘**：逐段足迹改为各向异性采样，修掉柔边图案在侧看机位变成硬边棱角的问题；抖动默认开启，压掉同心环。

> **图案图集必须带 mipmap**（Mip Gen Settings ≠ NoMipmaps，尺寸为 2 的幂）。缺 mip 的纹理会让抗混叠策略全部失效，子系统会给出告警。

---

## 4. 质量档

四档质量：低 / 中 / 高 / 超高。差别在每条光束的遮挡采样数与是否走半分辨率。

实际帧率取决于光束数量、锥角大小、相机距离与硬件——大锥角近距离光束是填充率主导，半分辨率与屏幕尺寸剔除是主要的调节手段。本文档不承诺固定帧率。

---

## 5. 使用注意

- 用户通常通过灯具定义与 DMX 间接控制它，不直接调；
- 没有光束时，先检查 Disable Beam、亮度、颜色，再看 UE 渲染设置；
- 体积光束是预演视觉效果，**不替代真实烟雾、现场灯具亮度和物理测量结果**。
