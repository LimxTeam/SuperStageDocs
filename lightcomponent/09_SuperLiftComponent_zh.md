# SuperLiftComponent

SuperLiftComponent 用于简单的 Z 轴升降。它接收归一化位置、升降范围和速度，然后把组件的**相对 Z 坐标**插值到目标位置。

## 参数

| 参数 | 作用 |
| --- | --- |
| InPosZ | 归一化位置，会被钳到 0–1。 |
| LiftRange | 行程长度。目标位置 = `LiftRange × InPosZ`，**基准是组件的相对坐标零点**，不是它被放进场景时的高度。 |
| LiftSpeed | 插值速度。 |

## 使用注意

- 组件自身不自动 Tick；通常由父级灯具或机械资产主动调用。
- 它只控制 Z 轴相对位置，不处理吊点安全、钢丝绳物理或真实机械反馈。
- 如果没有移动，检查父级资产是否在运行时持续传入控制值。
