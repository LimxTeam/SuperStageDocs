# SuperBeamComponent（材质光束 · Legacy）

> 适用版本：SuperStage 26H2.6 起
>
> **本组件属于旧材质管线。** 随包灯库已全量迁移到[体积光束](11_SuperVolumetricBeamComponent_zh.md)，材质光束保留仅供需要退回时使用，新内容不建议选用。
>
> 注意：**新从 GDTF 导入的灯，主发射器默认仍是材质光束**，需要在灯具编辑器里改成体积光束类型。

SuperBeamComponent 画的是**贴在网格上的光柱**——一条带光束材质的圆锥网格，和[体积光束](11_SuperVolumetricBeamComponent_zh.md)是两条不同的后端。它在聚光的基础上增加光束网格、光束材质、Gobo/纹理、颜色轮、棱镜、调焦、大气密度和光束禁用控制。

## 可见效果

- Dimmer、颜色和频闪会影响光束亮度。
- Zoom、Frost、Iris 会影响光束和光斑相关材质参数。
- Gobo 贴图、图案数量、图案索引、旋转速度和抖动速度会写入光束材质。
- 棱镜效果来自 SuperPrismPreset 和选择的棱镜层。
- Focus 用 0 到 1 控制清晰到模糊。
- Beam Disabled 打开时隐藏这条光柱，但不等同于删除灯具。

## 用户检查项

| 问题 | 检查 |
| --- | --- |
| 没有光束 | 检查 Beam Disabled、亮度、颜色、材质和 UE 渲染设置。 |
| Gobo 不显示 | 检查图集资源、图案数量和灯具库通道。 |
| 棱镜不显示 | 检查是否绑定 SuperPrismPreset，并选择了有效层。 |
| 遮挡距离异常 | 检查场景碰撞和可见性通道。 |

## 边界

体积光束是预演视觉效果，不替代真实烟雾、现场灯具亮度和物理测量结果。
