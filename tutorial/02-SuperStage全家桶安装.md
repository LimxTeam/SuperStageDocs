# SuperStage 全家桶安装教程

## 准备工作：下载全家桶

1. 访问 SuperStage 官方网站下载页面（[yunsio.com/download](https://yunsio.com/download)）。
2. 点击 **“免费下载”** 按钮，选择 **Windows 下载**。
3. 页面将跳转至百度网盘。请将网盘中的 **整个文件夹** 全部下载到本地。
   * *注：文件夹内包含 UE 主插件、数据传输工具、无人机控制软件、MA2 控台软件及破解补丁、示例工程和插件等必备模块。*

---

## 第一部分：安装 SuperStage 核心组件

### Step 1: 安装 UE 主插件 (SuperStageForUE)
1. 在下载的文件夹中找到 UE 插件安装包（如 `SuperStageSetup-26Q2.2.exe`），双击运行。
2. 连续点击“下一步”。
3. **选择版本**：勾选你电脑上已安装的 Unreal Engine 版本（本教程以 UE 5.7 为例）。
4. **勾选模板**：务必勾选底部的 **“安装项目模板”**，方便后续快速创建工程。
> **⚠️ 核心注意**：在点击“安装”前，**必须关闭所有正在运行的 Unreal Engine (UE) 编辑器！** 否则会导致文件被占用，安装失败或异常。
5. 同意许可协议，点击“下一步”直到安装完成。

### Step 2: 安装数据传输中枢 (SuperData)
1. 找到 `SuperData` 文件夹下的安装包（如 `SuperDataSetup-2.1.0.exe`），双击运行。
2. 选择 **“为所有用户安装”**。
3. 选择安装路径（可自定义文件夹）。
4. 点击“安装”，完成后退出。
*注：这是一个后台系统服务程序，安装后会在后台自动运行，日常使用无需手动打开。*

### Step 3: 安装无人机集控软件 (LimxDroneStudio)
1. 找到 `LimxDroneStudio` 文件夹，双击运行安装包。
2. 同样选择 **“为所有用户安装”**。
3. 选择安装路径并勾选创建桌面快捷方式，一直点击“下一步”完成安装。

## 第二部分：安装 MA2 控台软件（推荐）

如果您使用 MA2 进行灯光控制，请按照以下步骤安装软件及配置通信环境。如果您不需要使用 MA2，可跳过此部分。

### Step 1: 安装 MA2 onPC
1. 在下载包中找到 MA2 安装包 `grandMA2_onPC_3.3.4.3.exe`，双击运行。
2. 建议 **自定义安装路径**（尽量不要装在 C 盘的 Program Files 默认目录下，以免产生权限问题）。
3. 一路点击“下一步”直至安装完成。**安装完成后，请勿立即运行软件！**

### Step 2: 替换破解补丁
1. 在下载包中找到 MA2 的破解补丁文件 `gma2onpc.exe`。
2. 回到电脑桌面，右键点击刚生成的 MA2 快捷方式，选择 **“打开文件所在的位置”**。
3. 将破解补丁文件拖入该目录，并在弹窗中选择 **“替换目标中的文件”**。
4. 替换完成后，双击打开 MA2 软件。
5. 首次打开会弹出用户协议，将滚动条拉到最底部，点击 **“I AGREE”**（并勾选不再提示），随后将软件关闭。

### Step 3: 导入 SuperStage 预设工程 (Show File)
为了方便新手快速上手，全家桶内提供了一个已配置好所有灯具和插件的 MA2 模板工程。
1. 打开 Windows 文件资源管理器，进入 C 盘。
2. **开启隐藏文件显示**：点击顶部菜单的“查看” -> “显示” -> 勾选“隐藏的项目”。
3. 依次进入此路径：`C:\ProgramData\MA Lighting Technologies\grandma\gma2_V_3.3.4\shows`。
4. 将下载包里的预设工程文件（如 `SuperStage 26Q2.1.show.gz`）复制到该 `shows` 文件夹中。
5. 重新打开 MA2 软件，点击右侧的 **Backup** 按钮。
6. 点击 **Load Show**，选中刚才放入的 SuperStage 工程文件并加载。
   * *此时，所有的灯具和通信插件均已为您配置就绪。*

*(备选方案：手动安装 MA2 插件)*
如果您是进阶用户，希望在自己原有的 MA2 工程中使用 SuperStage，请将下载包 `plugins` 文件夹中的文件（如 `SuperData.xml` 等），复制到 `C:\ProgramData\...\gma2_V_3.3.4\plugins` 目录下。然后在 MA2 的 Plugin 窗口中编辑一个空插件位，点击 Import 导入 `SuperData` 即可。

## 第三部分：收尾与验证

### Step 1: 清理安装包
> **💡 强烈建议**：安装完成后，请将下载的所有 **安装包原文件删除**。
这样可以有效避免日后 SuperStage 发布新版本时，电脑里新旧安装包混淆，导致误装旧版本。

### Step 2: 在 UE 中创建 SuperStage 项目验证
1. 打开 Epic Games 启动器，或者直接进入 UE 的安装目录（如 `Engine\Binaries\Win64\UnrealEditor.exe`）手动启动引擎。
2. 在“新建项目”面板左侧，找到并选择 **“SuperStage”** 模板。
3. 在右下角配置项目名称和保存路径。
> **⚠️ 致命错误警告**：项目名称和保存路径 **必须全部为全英文或拼音**！严禁出现任何中文字符，否则会导致工程频繁报错或后期无法打包。
4. 点击“创建”。
5. 首次加载该项目需要编译大量着色器（Shader），耗时较长（右下角会有百分比提示），请耐心等待。
6. 编译加载完成后，进入主界面。您现在可以打开内容浏览器，将 SuperStage 文件夹中的各种灯具和舞台设备直接拖拽到场景中使用了！
