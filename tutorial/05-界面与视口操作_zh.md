# 界面与视口操作

欢迎来到 SuperStage 基础教程的第五章。在构建和编排复杂的系统时，一个高效、清晰的工作区至关重要。本篇文档将详细介绍 SuperStage 的主界面布局，并深入讲解视口（Viewport）的核心操作方法，帮助您在 3D/可视化空间中自由导航，从而更高效地管理和预览您的项目。

---

## 1. 主界面概览

当您打开 SuperStage 时，整个工作区被划分为几个核心功能区域。每个区域都承担着特定的任务，以保证工作流的顺畅。

`[插入截图：SuperStage 完整主界面，并用高亮框标出以下五个主要区域]`

### 1.1 菜单栏 (Menu Bar)
位于软件最上方，包含了所有的系统级操作，如**文件 (File)**的保存与打开、**编辑 (Edit)**操作、**视图 (View)**设置以及**帮助 (Help)**文档等。

### 1.2 工具栏 (Toolbar)
通常位于菜单栏下方或视口左侧。这里汇集了最常用的快捷工具，例如选择工具、移动工具、旋转工具以及缩放工具。通过工具栏，您可以快速切换当前的操作模式。

### 1.3 主视口 (Main Viewport)
占据界面最大面积的核心区域。这里是您预览场景、对象以及系统运行状态的“舞台”。所有的视觉交互和空间定位都在视口中完成。

### 1.4 层次结构/大纲面板 (Hierarchy/Outliner)
默认位于界面的左侧或右侧。该面板以树状图的形式列出了当前场景中的所有实体、节点和代理。您可以在这里快速选中特定对象，或者梳理它们之间的父子层级关系。

### 1.5 属性面板 (Properties Panel)
当您在视口或大纲面板中选中任何一个对象时，属性面板（通常在右侧）会显示该对象的所有详细参数，包括空间坐标（Transform）、材质、绑定接口及其他业务逻辑配置。

## 2. 视口基础导航操作

在 SuperStage 中，熟练掌握视口的导航操作是提升工作效率的基础。以下操作均围绕鼠标进行。

`[插入截图/动图：演示视口中鼠标平移、缩放和旋转的动作]`

### 2.1 视口平移 (Pan)
平移操作允许您在不改变观察角度和距离的情况下，上下左右移动您的视野。
* **操作方法**：按住 **鼠标中键 (Middle Mouse Button)** 并拖动鼠标。
* **适用场景**：当您需要查看视口边缘的物体，或者在大型场景中横向移动观察位置时。

### 2.2 视口旋转 (Orbit / Rotate)
旋转操作允许您围绕当前的观察中心点（或选中的物体）全方位地查看场景。
* **操作方法**：按住键盘上的 **Alt 键**（或 Option 键），同时按住 **鼠标左键** 并拖动。
* **适用场景**：全方位检查对象的各个侧面，或调整到最佳的观察视角。

### 2.3 视口缩放 (Zoom)
缩放操作用于拉近或推远您的视野，以便查看细节或总览全局。
* **操作方法**：
    1.  **方法一（平滑缩放）**：按住 **Alt 键**，同时按住 **鼠标右键**，向左或向右拖动鼠标。
    2.  **方法二（步进缩放）**：直接向上或向下滚动 **鼠标滚轮**。
* **适用场景**：聚焦于某个微小节点的参数，或者缩小视角查看整个 SuperStage 场景的宏观布局。

## 3. 视图切换与显示模式

为了适应不同的工作需求，SuperStage 提供了多种视图角度和渲染模式。

### 3.1 视角切换 (View Angles)
在进行精确对齐或调整位置时，透视视图可能会带来视觉误差。您可以使用快捷键快速切换到正交的二维视图：
* **顶视图 (Top)**
* **前视图 (Front)**
* **侧视图 (Side)**

`[插入截图：展示同一个物体在透视图、顶视图和前视图下的不同表现]`

### 3.2 显示模式 (Display Modes)
视口支持不同的渲染级别，您可以在视口右上角的显示设置栏中进行切换：
* **线框模式 (Wireframe)**：仅显示物体的轮廓线，占用资源极小，适合观察内部结构或在极其复杂的场景下提高运行帧率。
* **实体模式 (Solid / Shaded)**：显示物体的表面，不包含复杂的光影计算，是默认且最常用的工作模式。
* **材质/渲染模式 (Rendered)**：显示最终的材质、光照和阴影效果，用于最终效果预览。

## 4. 常用视口快捷键速查表

熟记以下快捷键，可以大幅减少鼠标在菜单栏上的移动，让您的操作更加行云流水：

| 操作指令 | 鼠标/键盘快捷键 | 功能说明 |
| :--- | :--- | :--- |
| **平移视野** | 按住中键 + 拖动 | 在同一平面内移动视角 |
| **旋转视野** | Alt + 左键拖动 | 围绕中心点旋转视角 |
| **平滑缩放** | Alt + 右键拖动 | 平滑地拉近或推远视角 |
| **滚轮缩放** | 滚动鼠标滚轮 | 步进式拉近或推远视角 |
| **聚焦选中物体** | F 键 (Focus) | 快速将当前选中的物体最大化居中显示在视口中 |
| **最大化视口** | 空格键 (Space) | 切换视口的全屏与窗口状态（将鼠标悬停在对应视口上） |

---
*提示：如果您在操作过程中迷失了视角（例如场景跑到了画面外），只需在大纲面板中点击任意一个您熟悉的物体，然后按下键盘上的 **F** 键，视口就会立刻自动重新对焦到该物体上。*
