
# 虚拟网卡（环回适配器）安装与配置

在单台电脑上同时运行 MA2 控台软件和 Unreal Engine 时，它们之间需要通过网络协议（如 Art-Net）进行通信。为了在没有物理网络连接或路由器的情况下实现稳定通信，我们需要在电脑上安装并配置一张“虚拟网卡”（Microsoft KM-TEST 环回适配器）。

---

### Step 1: 添加虚拟网卡硬件

1. **打开设备管理器**：
   * 右键点击 Windows 桌面底部的“开始”菜单图标（或按 `Win + X` 键）。
   * 在弹出的菜单中选择 **“设备管理器”**。
2. **添加过时硬件**：
   * 在设备管理器窗口中，随意点击选中列表中的任意一项（例如选中您的计算机名称）。
   * 点击顶部菜单栏的 **“操作”** -> **“添加过时硬件”**（部分系统显示为“添加旧版硬件”）。
3. **硬件安装向导**：
   * 弹出向导窗口后，点击“下一步”。
   * 选择 **“安装我手动从列表选择的硬件（高级）”**，点击“下一步”。
   * 在硬件类型列表中，向下滚动找到并选择 **“网络适配器”**，点击“下一步”。
4. **选择适配器型号**：
   * 在左侧的“厂商”列表中，找到并选中 **Microsoft**。
   * 在右侧的“型号”列表中，找到并选中 **Microsoft KM-TEST 环回适配器**（英文系统为 *Microsoft KM-TEST Loopback Adapter*）。
   * 点击“下一步”，再次点击“下一步”开始安装，完成后点击“完成”。

---

### Step 2: 配置虚拟网卡 IP 地址

为了让 MA2 和 UE 能够互相识别，我们需要为这张刚安装的虚拟网卡设置一个固定的静态 IP 地址（通常使用 Art-Net 标准的 `2.x.x.x` 网段）。

1. **打开网络连接面板**：
   * 按下键盘上的 `Win + R` 键，打开“运行”窗口。
   * 输入 `ncpa.cpl` 并按回车，直接打开“网络连接”控制面板。
2. **识别并重命名网卡（可选但推荐）**：
   * 在网络连接列表中，找到刚刚新增的网卡（通常会显示为“未识别的网络”，下方有 *Microsoft KM-TEST Loopback Adapter* 的字样）。
   * 为了方便后续区分，建议右键该网卡，选择 **“重命名”**，将其命名为 `MA2` 或 `ArtNet`。
3. **设置 IPv4 属性**：
   * 右键点击该虚拟网卡，选择 **“属性”**。
   * 在列表中找到并双击 **“Internet 协议版本 4 (TCP/IPv4)”**。
   * 选择 **“使用下面的 IP 地址”**。
   * **IP 地址**：输入 `2.0.0.100`（或者 2 网段的任意其他有效地址，只要确保不与其他设备冲突即可）。
   * **子网掩码**：单击输入框，系统会自动填充为 `255.0.0.0`。
   * 点击 **“确定”** 保存设置，再次点击“确定”关闭属性窗口。

> **💡 核心提示**：
> 配置完成后，您的电脑就已经具备了本地 Art-Net 通信的环境。**请务必重启 MA2 软件和 Unreal Engine**，这样它们才能读取并绑定到这个刚刚创建的 2 网段 IP 地址。

---

### Step 3: 在 MA2 中验证网卡

1. 打开 MA2 onPC 软件。
2. 点击顶部菜单栏的 **Setup**，进入 **MA Network Control**。
3. 在 **Station IP** 的下拉菜单中，检查是否能看到您刚才配置的 `2.0.0.100` 地址。
4. 如果能看到并选中该地址，说明虚拟网卡配置成功！点击 **Create Session** 创建会话即可准备与 UE 通信。
