# SuperAI 聊天面板

## 概述

`SSuperAIChat` 是 SuperAI 的核心交互界面，是一个基于 Slate 框架的编辑器内嵌聊天面板。支持自然语言输入、流式输出、工具调用可视化、思考过程展示、多会话管理等功能。

## 打开方式

- **菜单路径**：`Window → SuperStage → SuperAI 助手`
- **快捷方式**：面板支持停靠到编辑器任意位置，重启编辑器后自动恢复停靠布局
- **Tab ID**：`SuperAIChatTab`

### 工具栏

| 按钮 | 功能 |
|------|------|
| 新建会话 | 保存当前会话并创建空白会话 |
| 会话列表 | 弹窗显示所有历史会话，支持切换和删除 |
| 设置 | 打开配置对话框（API Key、模型、端点等） |

### 消息区域

- **用户消息**：蓝色气泡，显示用户输入文本
- **AI 回复**：灰色气泡，支持流式逐字显示
- **思考过程**：可折叠卡片，显示 AI 的推理思考内容
- **工具调用指示器**：显示 AI 调用了哪些工具，执行成功用 ✓ 标记，失败用 ✗ 标记

### 输入区域

- **多行输入**：支持 `SMultiLineEditableTextBox`，可输入多行文本
- **发送方式**：点击发送按钮或按 Enter 键
- **取消请求**：等待 AI 回复时，发送按钮变为取消按钮

### 状态栏

| 状态 | 含义 |
|------|------|
| MCP: 运行中 ● (绿色) | MCP 服务器已启动，外部客户端可连接 |
| MCP: 已停止 ● (灰色) | MCP 服务器未启动 |
| 就绪 | 等待用户输入 |
| 思考中... | AI 正在处理请求 |
| 执行工具... | AI 正在调用工具 |

## 流式输出

SuperAI 支持 SSE（Server-Sent Events）流式输出：

1. **开始响应**：创建新的 AI 回复气泡
2. **思考内容**：逐字追加到思考卡片中
3. **正式回复**：逐字追加到回复文本中
4. **工具调用**：插入工具调用指示器
5. **继续回复**：工具调用完成后，在新气泡中继续回复
6. **结束响应**：完成流式输出

## 会话管理

SuperAI 支持多会话管理，由 `FSuperAIChatSessionManager` 实现：

- **自动保存**：切换会话或新建会话时自动保存当前会话
- **会话恢复**：切换到历史会话时重建完整 UI（包括工具调用记录）
- **会话删除**：从会话列表中删除不再需要的会话
- **会话标题**：工具栏显示当前会话标题，便于识别

## MCP 服务器控制

聊天面板集成了 MCP 服务器的手动控制：

- **启动**：点击状态栏 MCP 按钮启动 HTTP 服务器
- **停止**：再次点击关闭服务器
- **状态指示**：绿色 = 运行中，灰色 = 已停止
- **默认行为**：MCP 服务器默认不自动启动，需手动开启
