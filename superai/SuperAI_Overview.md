# SuperAI — 智能助手使用指南

## 1. 简介

SuperAI 是 SuperStage 插件内置的 AI 智能助手。用户无需翻阅文档或观看教学视频，在编辑器内直接用**中文对话**，AI 即可给出操作指引并**直接帮助完成场景搭建**。

SuperAI 覆盖 **37 项操作能力**，涵盖以下工作领域：

| 能力领域 | 说明 |
|----------|------|
| **场景搭建** | 生成、复制、删除、排列场景中的灯具和物体 |
| **属性配置** | 读取和修改任意 Actor 的属性、位置、旋转、缩放 |
| **SuperStage 资产** | 浏览灯具库，一键放置并配置专业舞台灯具 |
| **材质编辑** | 创建材质、搭建节点图、编写自定义着色器 |
| **蓝图与动画** | 创建和编辑蓝图变量、函数、节点连线、动画状态机 |
| **资产管理** | 搜索项目资产、查询依赖关系、管理材质实例 |
| **视口控制** | 获取/设置摄像机位置、截取视口截图 |
| **文档与日志** | 自动查阅 SuperStage 产品文档回答使用问题 |

---

## 2. 打开聊天面板

SuperAI 的交互入口是编辑器内嵌的聊天面板，有以下三种方式打开：

- **菜单**：Window → 工具 (Tools) → SuperAI 助手
- **编辑器工具栏**：Play 区域的 **SuperAI** 按钮
- **编辑器状态栏**：底部状态栏的 **SuperAI** 按钮

面板支持停靠到编辑器任意位置，重启编辑器后自动恢复停靠布局。

### 工具栏

| 按钮 | 功能 |
|------|------|
| **新建会话** | 保存当前对话并创建空白会话 |

| **设置** | 配置 AI 模型服务（API 端点、密钥、模型等） |

### 消息区域

- **用户消息**：蓝色气泡
- **AI 回复**：灰色气泡，支持逐字流式显示
- **思考过程**：可折叠卡片，展示 AI 的推理过程
- **操作指示器**：显示 AI 执行了哪些操作，✓ 表示成功，✗ 表示失败

- 支持多行输入
- 按 **Enter** 发送，等待回复时发送按钮变为**取消按钮**

### 状态栏

| 状态 | 含义 |
|------|------|
| **MCP: 运行中** (绿色) | MCP 服务器已启动，外部客户端可连接 |

- **自动保存**：切换会话或新建会话时自动保存当前对话
- **会话恢复**：切换到历史会话时完整恢复对话记录
- **会话删除**：从会话列表中删除不再需要的对话

## 4. AI 模型配置

SuperAI 支持接入**多个 LLM 服务**（如 OpenAI / DeepSeek / 通义千问等），可自由切换。点击聊天面板工具栏的 **设置** 按钮打开配置对话框。

每个服务预设可配置以下选项：

| 配置项 | 说明 |
|--------|------|
| **预设名称** | 显示用名称，如「OpenAI GPT-4o」「DeepSeek V3」 |
| **API 端点** | 服务商提供的 API 地址（OpenAI 兼容格式） |
| **API 密钥** | 服务商提供的密钥（本地加密存储，不上传） |
| **模型名称** | 要调用的模型，如 `gpt-4o`、`deepseek-chat` |
| **采样温度** | 0.0-2.0，数值越低回复越确定（默认 0.7） |
| **最大输出长度** | 单次回复的最大 Token 数（默认 4096） |
| **请求超时** | HTTP 超时秒数（默认 120） |
| **流式输出** | 是否逐字显示回复（默认开启） |

> **提示**：SuperAI 兼容所有 OpenAI API 格式的服务商，包括自建模型推理服务。

## 5. MCP 外部接入

SuperAI 内置 MCP（Model Context Protocol）服务器，允许外部 AI 客户端（如 Claude Desktop、Cursor 等）通过标准协议调用全部 37 项操作能力。

| 配置项 | 说明 |
|--------|------|
| **启动方式** | 聊天面板状态栏点击 MCP 开关按钮 |
| **端口** | 13090 |
| **协议** | Streamable HTTP（JSON-RPC 2.0） |
| **安全控制** | 手动启停，不使用时不占用端口和资源 |

## 7. 场景搭建

SuperAI 可以帮你在场景中放置、查找、复制、删除、整理各种物体。

### 放置物体

你可以用自然语言描述要放置的物体，AI 会自动处理：

> **用户**：放一个聚光灯在 (0, 0, 500) 的位置
>
> **用户**：在场景里加一个立方体
>
> **用户**：帮我放一个摄像机，对准舞台中心

**支持的物体类型**：所有 UE 内置 Actor（灯光、摄像机、雾效、后处理等）、基础形状（立方体、球体、圆柱、圆锥、平面）、SuperStage 灯具和舞台资产（通过资产库搜索）。

### 查找和选择物体

> **用户**：场景里有哪些灯光？
>
> **用户**：帮我选中所有名字里带"Spot"的灯
>
> **用户**：选中的这些灯是什么参数？

### 复制、删除、重命名

> **用户**：把这个灯复制一份，往右移 200 厘米
>
> **用户**：删掉场景里所有的 PointLight
>
> **用户**：把这 8 台灯重命名为 SpotLight_1 到 SpotLight_8

### 显隐和文件夹整理

> **用户**：先把舞台上的桁架都隐藏，我要单独调灯光
>
> **用户**：把所有灯光放到 Lighting 文件夹下

### 撤销与关卡

所有操作均支持 **Ctrl+Z 撤销**。也可以直接对 AI 说「撤销」「重做」。

> **用户**：帮我新建一个空关卡
>
> **用户**：保存当前关卡

SuperAI 可以读取和修改场景中任意 Actor 的属性值，包括位置、旋转、缩放等变换参数。

### 查看属性

> **用户**：列一下这个灯有哪些可调参数
>
> **用户**：这个灯的亮度是多少？
>
> **用户**：看看 Cube_01 的位置

### 修改属性

> **用户**：把这个灯的亮度调到 0.8
>
> **用户**：把 Cube_01 移到 (100, 200, 0)
>
> **用户**：让这个灯朝下旋转 45 度

### 批量修改

> **用户**：把场景里所有 SuperStageLight 的亮度都设为 0.5
>
> **用户**：把选中的这些灯的颜色都改成红色

### 使用提示

- 不确定有哪些属性可调时，先让 AI「列出属性」

- AI 会自动根据你的视角方向理解「左右前后」等方位词

## 9. SuperStage 灯具与舞台资产

这是 SuperAI 的核心能力之一——帮你从 SuperStage 资产库中找到合适的灯具和舞台设备，放置到场景中并配置好参数。

### 资产库分类

**灯具类**
- **Moving Head**：电脑摇头灯（切割灯、染色灯、光束灯等）
- **LED**：LED 帕灯、LED 条灯等
- **Conventional**：传统灯具（成像灯、菲涅尔灯等）
- **Effect**：效果灯具（频闪灯、追光灯等）

**舞台结构**
- **Truss / Gantry**：桁架、龙门架（直线、圆形、弧形、网格、塔形等）
- **Scaffold**：脚手架（直线、弧形）

**舞台装饰**
- **Drape**：幕布（多种褶皱和开合方式）
- **Crowd**：程序化人群

### 使用示例

> **用户**：帮我找一个 LED 帕灯
>
> **AI**：找到以下 LED 灯具...（列出可用资产，推荐最匹配的）
>
> **用户**：就用第一个，在舞台上方 6 米放一排 8 台，间距 2 米
>
> **AI**：已放置 8 台灯具并配置好参数。（自动完成：放置 → 切换控制模式 → 配置属性 → 设置位置）

> **用户**：帮我搭一个 10 米宽的龙门架
>
> **用户**：加一块黑色幕布挡住后面

### 灯光朝向

描述灯具朝向时，可以直接说方向：

> **用户**：让灯朝下照
>
> **用户**：让灯对准舞台中心 (0, 0, 0)

## 10. 材质编辑

SuperAI 拥有完整的材质图编辑能力，覆盖从创建材质到构建节点图的全流程。

### 可以做什么

- **创建材质和材质函数**
- **添加和连接节点**（支持所有 UE 材质表达式类型）
- **编写 Custom HLSL 着色器**（自定义输入/输出引脚）
- **批量操作**（一次添加多个节点、建立多个连接）
- **自动布局**（整理节点图排布）
- **纹理管理**（搜索项目内纹理、从文件导入纹理）
- **材质实例**（创建实例、设置标量/向量/纹理参数、赋给物体）

### 使用示例

> **用户**：帮我创建一个半透明的红色发光材质
>
> **AI**：好的，我来创建材质并设置节点...（自动创建材质 → 设置为半透明 → 添加颜色和自发光节点 → 连接到输出 → 编译保存）

> **用户**：给 Cube_01 换一个金属质感的蓝色材质
>
> **AI**：我先创建一个材质实例，然后赋给它...

> **用户**：在材质里加一个 Custom 节点，写一个正弦波动画效果

### 使用提示

- 修改材质后 AI 会自动编译和保存
- 复杂材质 AI 会自动使用批量操作提高效率
- 可以让 AI 截图确认材质效果

## 11. 蓝图与动画

SuperAI 可以查询和修改蓝图与动画蓝图。

### 蓝图操作

- **创建蓝图**：指定名称和父类
- **变量管理**：添加/删除变量（支持 bool、int、float、字符串、向量等类型）
- **函数管理**：添加/删除自定义函数
- **节点操作**：在事件图中添加节点（函数调用、分支、事件、变量读写、数学运算等）
- **连线操作**：建立和断开节点引脚连接
- **自动编译**：修改后自动编译蓝图

### 动画蓝图

- **查看结构**：获取动画蓝图的状态机、状态、转换概览
- **状态机**：创建状态机、添加/删除状态、添加/删除状态转换
- **设置动画**：为状态绑定动画序列、混合空间或蒙太奇
- **搜索动画**：查找项目中兼容的动画资产

### 使用示例

> **用户**：帮我创建一个 Actor 蓝图，加一个 Health 变量
>
> **用户**：在动画蓝图里创建一个 Locomotion 状态机，加上 Idle 和 Walk 两个状态

## 12. 资产管理

SuperAI 可以帮你管理项目中的资产文件。

### 可以做什么

- **搜索资产**：在项目中按类型（蓝图、模型、纹理、材质、音效等）、路径、名称搜索资产
- **查看信息**：获取资产的类型、路径、大小等信息
- **依赖分析**：查看一个资产依赖了哪些其他资产
- **反向引用**：查看一个资产被哪些其他资产引用——删除或修改资产前必备
- **材质实例**：创建材质实例、设置参数、赋给场景物体

### 使用示例

> **用户**：项目里有哪些纹理？
>
> **用户**：M_Ground 这个材质被哪些资产用到了？
>
> **用户**：帮我创建一个 M_Base 的材质实例，粗糙度设为 0.3，颜色设为红色

## 14. 常用工作流速查

### 放置 SuperStage 灯具

> 告诉 AI 你需要什么灯 → AI 从资产库找到灯具 → 放置到场景 → 配置参数 → 设置位置

### 批量调整场景灯光

> 告诉 AI 要调整哪些灯、改什么参数 → AI 自动批量修改

### 创建完整材质

> 描述你想要的材质效果 → AI 创建材质 → 搭建节点图 → 编译保存

### 回答 SuperStage 使用问题

> 直接提问 → AI 自动查阅文档 → 给出回答

### 理解你的视角

> AI 获取你的摄像机位置 → 计算相对方位 → 在你描述的位置放置物体
