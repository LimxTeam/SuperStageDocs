# 选灯与编程

> 适用版本：SuperStage 26H2.6 起 ｜ 前置阅读：[控台总览](00_Console_Overview_zh.md)

本文说明在 SuperConsole 里怎么选灯、改参数，以及怎么把结果存成编组和预设。

---

## 1. 选灯

三条路：

| 途径 | 说明 |
| --- | --- |
| Fixture Sheet | 在灯具表里点选 |
| Layout 面板 | 在灯位图上点选 |
| 命令行 | `Fixture 1 Thru 20`、`Group 3` |

选择本身是可撤销的。

---

## 2. 编程器

选中灯之后，改的值先进**编程器**。编程器是一层暂存：它压在所有回放之上，直到你清掉它或把它存进某个对象。

改值的方式：

- **编码轮拨动**——编码器栏上一排轮子，一次手势记一步撤销；
- **键入具体数值**——点编码轮弹出数字输入框；
- **命令行**；
- **Color Picker 面板取色**。

> Fixture Sheet 只用来**选**和**看**，不在那里改值：点选、`Ctrl+点击`加选、`Shift+点击`连选、全选、取消。

属性按类别分组，与预设类别一致：Dimmer、Position、Gobo、Color、Beam、Focus、Control、Shaper、Strobe、Prism、Frost、Effect、Other。

---

## 3. 编组（Group）

编组存的是**一批灯**，不含数值。

- 选好灯 → **Store** → **Group** → 指定槽位号；
- 命令行：`Store Group 5`；
- 复制 / 移动：`Copy Group 1 At 5`、`Move Group 1 At 5`。

编组槽位在 Groups 面板里按格显示，外观可自定义（见第 5 节）。

---

## 4. 预设（Preset）

预设存的是**一批属性值**。每条记录属性名、属性类别与数值（0–100）。

预设按类别归档，与属性分组一致：

| 类别 | 典型内容 |
| --- | --- |
| All | 全部属性 |
| Dimmer | 调光 |
| Position | Pan / Tilt |
| Gobo | 图案轮与旋转 |
| Color | 混色、色轮、色温 |
| Beam | 变焦、光圈 |
| Focus | 调焦 |
| Control | 控制通道 |
| Shaper | 切割 |
| Strobe | 频闪 |
| Prism | 棱镜 |
| Frost | 雾化 |
| Effect | 效果 |

操作：

- **Store** → **Preset** → 类别 + 槽位号；
- 命令行：`Store Preset 2`、`Copy Preset 1 At 5`、`Move Preset 1 At 5`、`Delete Preset 3`。

---

## 5. 槽位外观

编组槽、预设槽与侧边栏视图槽共用同一套**命名外观**，四层各有独立开关：

| 层 | 说明 |
| --- | --- |
| 名称 | 槽位文字 |
| 底色 | 背景色 / 文字色 / 强调色 |
| 图片 | 一张贴图，可选铺满（Cover）或完整放入（Contain） |
| 涂鸦 | 手绘标记 |

要点：

- 四个开关的组合就是"名称模式"——只显示图片、只显示名称、图片压着名称、纯色块，都是同一份数据的不同呈现；
- **涂鸦按笔存储并使用归一化坐标**，所以同一份涂鸦在侧边栏小方块和编辑器大预览上落点一致；
- **图片按引用存储，不内嵌**。同一张图被多个槽位使用，不会在演出文件里重复占体积。

---

## 6. 清编程器

把编程器清空，让回放重新接管输出。清编程器不影响已经存好的编组、预设和 CUE。

---

## 7. 常见问题

### 推了值但灯没反应

1. 确认这支灯在控台的 Patch 面板里存在，且 Universe / 地址与场景一致；
2. 确认这条属性在灯具定义的绑定里存在（见 [灯具编辑器](../fixture/03_FixtureEditor_zh.md) 的 Validation 页）；
3. 确认场景灯具的 `ControlMode` 是 `DMX`，不是 `Property`。

### 存了预设，调用之后只有一部分灯变化

预设记的是属性名。不同型号灯具的属性名不一致时，只有名字对得上的那部分会响应。

### 编组存错了槽位

`Move Group <旧> At <新>`，或者直接在原槽位重新 Store 覆盖。整个操作都在撤销栈里。
