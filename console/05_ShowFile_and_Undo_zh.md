# 演出文件与撤销

> 适用版本：SuperStage 26H2.6 起 ｜ 前置阅读：[控台总览](00_Console_Overview_zh.md)

---

## 1. 演出文件

演出文件保存控台的全部内容：编组、预设、CUE、效果、时间线、时间码、布局与视图。

在 **Settings → Show** 页新建、打开、保存（编码器栏右侧的 ⚙ 按钮打开设置）。控台记录的"上次打开的演出文件"存在 `SuperStage/Config/SuperConsolePro.ini`。

### 1.1 版本

当前格式版本 **2.7**。

| 版本 | 变化 |
| --- | --- |
| 2.3 起 | 槽位外观（名称与颜色） |
| 2.4 起 | 效果池 |
| 2.5 起 | 结构体带块长前缀，字段增删不再让整份文件读错位 |
| 2.6 起 | 时间线记录时间码帧率 |
| **2.7 起** | 时间线补齐六个字段：时间线名称、节拍细分、音频轨音量、片段与快照的关联、音频淡入与淡出时长 |

### 1.2 兼容性

> **本版可以正常读取所有 2.x 旧演出文件**，槽位名称与颜色会自动转换为新的外观格式。
>
> **反过来要当心。** 2.7 存出的文件拿回旧版本打开时，旧版本不会报错——它只是读不到 2.7 新增的那几个字段，那些内容会静默回到默认值。所以打算回退版本的话，**先另存一份副本**。

演出文件是本产品自有格式，与第三方控台工程文件不互通。

## 2. 撤销

撤销覆盖**设置以外的全部操作**：

| 覆盖 | 具体是什么 |
| --- | --- |
| 编程器与选择 | 改值、选灯、清编程器 |
| 编组 / 预设 / CUE | 存储、更新、改名、删除、复制、移动 |
| 效果 | 步骤、波形、相位、各项运行参数 |
| 视图布局 | 加窗口、删窗口、拖动与改大小、切换视图 |
| 灯位图 | 灯位的摆放 |
| 时间码与时间线 | 轨道、片段、时间码 CUE |
| 回放键 | 执行器的快捷键绑定 |

撤销栈里每一条都带一句人话标签（例如 `Store Group 2`），按 Undo 之前能看到自己要撤的是哪一步。

### 2.1 合并规则

| 情形 | 行为 |
| --- | --- |
| **有明确起止的拖拽**（拖转轮、拖滑块） | 整段手势只记一条。这是最准的一种——它就是用户心里的"一个动作" |
| **没有起止的离散步进**（滚轮、连点） | 同一个合并键在 **0.5 秒**时间窗内的连续改动并成一条。手停这么久就算一个动作结束 |
| **换了操作对象** | 先把上一条结掉再开新的 |
| **嵌套操作** | 按深度合并：只有最外层负责压栈，标签取最外层的（如 `Store Group 2` 而不是 `Store Group`） |
| 删除多个对象 | 合成一次撤销 |

**撤销栈深度上限 100 条。**

**前后状态完全一样的操作不压栈**——比如对空选择按 Full。压进去只会让撤销键变亮却撤不出任何效果。

> 合并中的那条会在任何**非合并操作之前**先落栈。否则"转两下滚轮、再删一个编组"会把删除的前状态错记成转之前的样子。

### 2.2 不在撤销范围内

- **设置**（Settings 的三页：Show / Patch / DMX）不进撤销栈；
- **回放本身不进撤销栈**。跑时间线、按执行器不会往栈里塞记录——撤销键留给你自己做过的编辑；
- **打开一个演出文件会清空撤销栈**，不会撤回上一个演出的内容。
