# 效果（Frame）

> 适用版本：SuperStage 26H2.6 起 ｜ 前置阅读：[选灯与编程](01_Programming_zh.md)

SuperConsole 的效果引擎叫 **Frame**。一个 Frame 由若干**步骤（Step）**组成，按波形在步骤之间循环，并可以在选中的一批灯之间分配相位。

换句话说：**步骤定义要经过哪些状态，波形定义怎么在它们之间走，相位定义每支灯从哪一步开始走。**

---

## 1. 步骤

每个步骤记录若干属性的目标值：

| 字段 | 说明 |
| --- | --- |
| Attribute Name | 属性名 |
| Absolute Value | 绝对值 0–1，`-1` 表示未设置 |
| Relative Value | 相对值 −1 ~ 1，`0` 表示无偏移 |
| Use Relative | 用相对值还是绝对值 |
| Width | 这一步占整个周期的比例 |
| Enabled | 是否启用 |

绝对值是"走到这个值"，相对值是"在当前值上偏移这么多"。做位置摆动一类效果用相对值，做固定色序用绝对值。

---

## 2. 逐属性参数

同一个 Frame 里，每条属性可以有自己的一套运行参数：

| 参数 | 说明 |
| --- | --- |
| 参数 | 取值 | 默认 | 说明 |
| --- | --- | ---: | --- |
| Waveform | Rectangle / Sawtooth / Sine / Cosine | Sine | 矩形是瞬时跳变，锯齿是线性上升，余弦相当于正弦偏 90° |
| Speed | 0.1 – 600 BPM | 60 | 这条属性自己的速度 |
| Width | 0 – 100 % | 100 | 占空比：波形在一个周期里占多少。10% 就是短脉冲，适合频闪 |
| Attack | 0 – 100 % | 100 | 上升过渡占的**时长比例**，0 = 瞬变，100 = 全程平滑。**只在矩形波下有意义** |
| Decay | 0 – 100 % | 100 | 下降过渡占的时长比例，同上 |
| Phase Offset | −180 – 180 ° | 0 | 这条属性整体的相位偏移，叠在逐灯相位之上 |
| Phase Range | 度 | 360 | 相位在一组灯之间铺开的总跨度 |
| Wings | 1 – 32 | 1 | 翼数，把选择对折成对称组 |
| Block | 1 – 32 | 1 | 分块大小，块内同相位 |
| Group | 1 – 32 | 1 | 分组数 |
| Random Phase | 0 – 100 % | 0 | 在规则相位之上再叠一个逐灯随机偏移。0 = 完全规则，100 = 完全打散。同一盏灯每帧拿到的偏移都一样，所以看到的是散开的效果而不是抖动 |

---

## 3. 相位分配

相位在选中的一批灯之间怎么铺开，由**选择工具**决定——效果本身不重排顺序，它按选中的顺序发相位。配合 Wings / Block / Group 可以做出对称、分块、隔灯等常见排布。

---

## 4. 效果编辑器工具栏

Frame Editor 面板左侧是一竖排工具按钮，自上而下：

| 按钮 | 作用 |
| --- | --- |
| **A+** | 没选中步骤时新建一步；选中了步骤则把改动并进这几步 |
| **R-** | 移除步骤 |
| **P** | 调整相位分配 |
| **W** | 选择波形 |
| **Sp** | 速度。这一页里还有 **TAP**（跟着音乐点速度主控）与 **SYNC**（这条效果改跟速度主控走，不用自己的 BPM） |
| **Wi** | 占空比 |
| **At** | 上升过渡。**只在矩形波下出现**，其余波形下这个按钮整个隐藏 |
| **Dc** | 下降过渡。同上 |
| **Wg** | 翼数 |
| **Bl** | 分块大小 |
| **Gr** | 分组数 |
| **Di** | 播放方向，正放 / 倒放 |
| **Rd** | 随机相位，把逐灯相位打散 |
| **Fd** | 效果淡入淡出（秒）。启动时渐起、释放时渐落，不是硬切 |
| **Ms** | 效果主控：幅度、速度倍率、整体相位。幅度是向**当前台上的值**收敛的，调小是让效果围着现状变窄，不是渐变到黑 |
| **?** | 帮助，列出全部按钮与步骤栏用法 |

竖排的最下方是**播放 / 停止**按钮。

---

## 5. 效果在输出仲裁里的位置

效果属于**回放层**，与时间线 / 时间码 CUE / CUE 同级：

- 强度属性走 HTP（取大）；
- 其余属性走 LTP（先比来源优先级，同来源比写入时间）；
- 编程器压过效果，高亮再压过编程器。

详见 [CUE 与回放](02_Cues_and_Playback_zh.md) 第 3 节。
