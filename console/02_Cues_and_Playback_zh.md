# CUE 与回放

> 适用版本：SuperStage 26H2.6 起 ｜ 前置阅读：[选灯与编程](01_Programming_zh.md)

本文说明 CUE 怎么存怎么放，多个回放同时压一盏灯时结果怎么定，以及时间线与时间码。

---

## 1. CUE

CUE 存的是一份灯光状态快照。

- **Store** → **Cue** → 编号；命令行 `Store Cue 2`；
- 更新：`Update Cue 2`；
- 复制 / 移动：`Copy Cue 2 At 6`、`Move Cue 2 At 6`；
- 删除：`Delete Cue 2`。

**CUE 表就是 Playback 面板**：一个 CUE 占一个槽位，槽位按页翻，页码栏在面板顶部。没有另外一个叫 Cues 的面板。

---

## 2. 执行器

Playback 面板的每个槽位就是一个执行器：**左键按下触发，松开结束**。没有推杆——不管是实体的还是屏幕上的，这一版都没有。

**右键一个槽位**弹出它的菜单：

| 分区 | 项 | 说明 |
| --- | --- | --- |
| Trigger Mode | Toggle | 点一下开，再点一下关 |
| | Momentary | 按住有效，松手释放（带淡出） |
| | Flash | 按住有效，松手立刻断（不淡出） |
| Edit | Edit CUE | 把这条 CUE 读回编程器继续改 |
| | Update CUE (Replace) | 用当前编程器内容整条替换 |
| | Merge into CUE | 把编程器内容并进去：新灯新属性追加，已有的更新 |
| | Rename / Delete | 改名 / 删除 |
| Copy / Move | Copy → Paste | 复制到剪贴板，在目标槽位粘贴，得到一份副本 |
| | Move… → Move Here | 标记待移动，再在目标槽位选 Move Here；**时间线片段与快捷键的引用会自动跟过去** |
| Shortcut | Set Shortcut… | 给这个槽位绑一个键盘快捷键 |
| （空槽位） | Save CUE Here | 把当前编程器直接存成这个槽位的 CUE |

**松开一个执行器不会清掉另一个执行器在同一盏灯上的输出。**

---

## 3. 输出仲裁

多个来源同时压一盏灯的同一条属性时，按三段合并，顺序固定：

```text
1. 默认值层      灯具定义里的默认值。只作兜底，任何回放或编程器有值都会盖掉它
       ↓
2. 回放层        时间线 / 时间码 CUE / CUE / 效果
       ↓            · 强度属性走 HTP：谁大谁赢，与来源优先级无关
                    · 其余属性走 LTP：先比来源优先级，同来源比写入时间
       ↓
3. 编程器        盖过上面所有回放 —— 手上正在调的值必须看得见
       ↓
4. 高亮          盖过编程器 —— 「先让我看见这几支」优先级最高
```

几个要点：

- **默认值不参与 HTP 竞争**。灯具定义里默认值不为 0 的强度通道，如果参与取最大值，输出会被永久钉在那个值上再也降不下来；
- **强度走 HTP 是有意的**。底光被一个更暗的效果盖上去时，真实控台取两者较大者。平铺覆盖会让低优先级那份直接消失，结果是底光反而变暗；
- **按 CUE 分层**：同一条 CUE 无论由 Playback 面板还是时间线片段驱动，都落在同一层；不同 CUE 各占一层；
- **只有真正的调光通道走 HTP**。没有独立 Dimmer 通道的 LED 灯，它的加色通道算作**虚拟调光**：跟着回放电平一起缩放，但合并方式仍是 LTP（后写的赢），不取最大值。

### 3.1 高亮

编码器栏上的 **Highlight** 按钮，把当前选中的灯推到各自的高亮值（强度满、光束打开、无图案），让人一眼在台上认出是哪几支。它压在编程器之上，所以正在编的值也挡不住它。再按一次退出高亮。

Running 面板显示当前正在跑的回放，分 **Cues / Effects / Presets / All** 四页。

## 4. 时间线

时间线在 **Timecode 面板**里，不是一个独立面板。

- 两种轨道：**CUE 轨**与**音频轨**，用轨道区上方的 `+ CUE`、`+ Audio` 添加；
- 片段拖放安排；
- 同一条轨道上的重叠片段各自独立释放，不会互相冲掉激活记录；
- **Export Sequence** 把时间线的 DMX 与音频烘成一条关卡序列。

> 效果不能单独放上时间线。想让效果跟着时间线跑，把它包进一条 CUE，再把那条 CUE 放到 CUE 轨上。

---

## 5. 时间码

**帧率是时间线自己的属性**，显示与导出读同一个来源。

支持的帧率：

| 帧率 | 说明 |
| --- | --- |
| 24 fps | Film |
| 25 fps | PAL / EBU |
| 29.97 fps | NTSC 丢帧 |
| 30 fps | SMPTE |
| 50 fps | |
| 59.94 fps | 丢帧 |
| 60 fps | |

NTSC 帧率走精确有理数（29.97 是 30000/1001，不是 29.97 浮点），丢帧编号按标准。

显示格式为 **HH:MM:SS:FF**，超过一小时不会溢出。丢帧帧率（29.97 / 59.94）按 SMPTE 惯例把最后一个分隔符写成分号，显示成 **HH:MM:SS;FF**——扫一眼就知道当前是不是丢帧。

## 6. 常见问题

### 两个回放压同一盏灯，结果不是我要的

先分清属性类型：强度走 HTP（取大），其余走 LTP（后写的赢 / 高优先级赢）。想让某一份必定赢，把它放到更高优先级的来源上，或者用编程器临时压住。

### 灯卡在台上不灭

看 Running 面板里是不是还有没释放的回放。清编程器不会释放回放。

### 选中的灯在台上认不出来

按编码器栏的 **Highlight**，选中的灯会推到高亮值。认完再按一次退出。

### 时间码对不上

确认时间线自己的帧率设置，以及外部时间码源的帧率是否一致。29.97 与 30 不是一回事。
