# 激光效果系统

> 适用版本：SuperStage 26H2.6 起 ｜ 前置阅读：[激光动画资产](01_LaserAnimationAsset_zh.md)

效果挂在图层上，组成**效果栈**，按顺序求值。分类沿用专业激光软件的通行做法，从别处过来的人不必重学一套。

---

## 1. 六类效果

| 类别 | 说明 |
| --- | --- |
| **Oscillator** | 连续振荡：目标在起点与终点之间按波形往复 |
| **Keyframes** | 关键帧：每个效果自带一条局部时间轴，带可拖拽曲线编辑器 |
| **Color** | 颜色：色标线 × 应用域 × 混合模式 |
| **Points** | 点级操作。激光独有，视频软件里没有对应物 |
| **Filter** | 清理与优化 |
| **Device Chase** | 设备轮播：内容在多个投射区域之间走位，带步间淡入淡出（见 §9） |

> 关键帧与"没有固定时长"不冲突：关键帧活在单个效果内部的周期里，资产整体依然没有总时长。

---

## 2. 时间基

| 时间基 | 说明 |
| --- | --- |
| **Seconds** | 秒。用于不应随节拍漂移的效果 |
| **Beats** | 拍，由资产的 Tempo 驱动。演出跟着音乐走时用这个 |

只给赫兹等于逼用户手算 BPM，所以两种都提供。

---

## 3. 作用目标

Oscillator 与 Keyframes 可以驱动以下 17 个目标：

| 目标 | 说明 |
| --- | --- |
| **Position** | 位置，**双轴当一个值**。做运动路径用它——拆成 Position X / Y 两个效果就是两张关键帧表，得手工对齐，动一个键就散 |
| **Position X** / **Position Y** | 单轴位置 |
| **Rotation** | 旋转 |
| **Scale** | 两轴一起缩放 |
| **Scale (X/Y)** | 缩放当一个双轴值，**一组关键帧就能做挤压拉伸** |
| **Scale X** / **Scale Y** | 单轴缩放 |
| **Skew X** / **Skew Y** | 斜切 |
| **Wave** | 把点**垂直于路径**推开。配 `Along Path` 分布就是经典波浪 |
| **Ripple** | 把点**沿半径**推开。涟漪与呼吸感 |
| **Twist** | 每个点按分布量递增地旋转，拧麻花 |
| **Brightness** | 亮度 |
| **Visibility** | 信号低于阈值的点直接灭掉。**逐段显形、虚线、频闪都是它** |
| **Hue Shift** | 在点已有颜色的基础上偏移色相 |
| **Saturation** | 饱和度 |

## 4. 波形与运行方式

### 4.1 十三种波形

| 波形 | 说明 |
| --- | --- |
| **Sine** | 正弦 |
| **Ping-Pong** | 三角波 |
| **Square** | 硬切开关。**频闪就是它** |
| **Linear** | 斜坡走到头直接跳回。**连续旋转、滚动渐变要用它** |
| **Linear (Reverse)** | 反向斜坡 |
| **Accelerate** | 先慢后快 |
| **Decelerate** | 先快后慢 |
| **Ping-Pong (Smooth)** | 走到终点再走回来，不跳回 |
| **Discrete Steps** | 在固定几个档位之间跳，不连续扫 |
| **Random** | **每个周期换一次**随机值并保持到下个周期。不是每帧乱抖 |
| **Bounce** | 冲过终点再以递减的幅度弹回，像东西掉下来 |
| **Random Positions** | 每个周期跳到**固定几个位置中的随机一个**。与 Random 的区别是后者可以落在任意值上——只在几个位置之间跳，随机光束运动才像是编排过的而不是噪声 |
| **Custom Waveform** | 自己在效果的曲线编辑器上画 |

波形下拉里直接列出 **2 / 4 / 8 / 16 阶梯**与 **2 / 3 / 4 / 8 / 16 随机落点**，不用自己配。

### 4.2 三种轨迹形状

**只对双轴目标有意义**（Position、Scale (X/Y)）：

| 轨迹 | 说明 |
| --- | --- |
| **Linear** | 两轴同向走，用角度决定朝哪边 |
| **Circle** | 两轴差 **1/4 周期**，图形走圆 |
| **Figure 8** | 一轴速率是另一轴的两倍，走 8 字 |

> 双轴目标只给一个波形是不够的：绕圈需要两个轴差 1/4 相位。拆成两个效果去手动对齐相位是最容易错、也最难看出错的做法，所以这里直接给轨迹形状。

## 5. 分布

效果在一帧内容里怎么铺开，由分布方式决定：

| 分布 | 说明 |
| --- | --- |
| **Whole Frame** | 所有点同一个值，整帧一起动 |
| **Along Path** | 按在扫描路径上的先后，从第一个点到最后一个 |
| **Radius** | 按到中心的距离 |
| **Angle** | 按绕中心的角度，一整圈 0 到 1 |
| **By X** / **By Y** | 按坐标 |
| **Symmetrical X** / **Symmetrical Y** | 按到中心的距离，两侧镜像 |
| **Random** | 每个点一个**固定**的随机量。逐帧保持不变，不会沸腾 |

> **`Along Path` 是激光独有的那一个**：一束激光在物理上就是一条一维路径——波浪能"跑"、渐变能"拉开"、图形能"逐段画出来"，全靠它。

---

## 6. 颜色效果

**颜色不再一律彩虹。**

应用域（8 种）：By Points、By X、By Y、By Radius、By Angle、Symmetrical X、Symmetrical Y、By Time

混合模式（5 种）：

| 模式 | 说明 |
| --- | --- |
| Replace | 直接替换 |
| Hue + Saturation | 换色相与饱和度 |
| Hue Shift | 在原色基础上偏移 |
| **Brightness Only** | 完全不改色相——**单色激光唯一能用的模式** |
| Multiply | 相乘 |

其余参数：

| 参数 | 默认 | 范围 | 说明 |
| --- | ---: | --- | --- |
| **Stops** | — | — | 色标线上的色标。**两个色标 + 关掉 Discrete 就是一条双色渐变** |
| **Discrete** | 关 | — | 吸附到最近的色标而不是插值，给出**成块的色带**而不是渐变 |
| **Repeats** | 1 | 1–32 | 色标线在一帧里重复几遍 |
| **Speed** | **0** | −8–8 | 色标线的滚动速度，单位是"每周期几个线长"。**默认 0 即静止** |

所以颜色不再一律是整条彩虹：想要双色、三色，就放两三个色标。

> 色相到 RGB 的换算是连续的，不走 8 位量化，**滚动时不会出台阶状色带**。

## 7. Points（点级操作）

这一类改的是**点流本身的构成**，不是几何也不是颜色。**光束秀全靠它**——振镜停在一个位置重复输出同一个点，光才够亮。

| 操作 | 说明 |
| --- | --- |
| **Point Repeat** | 每个点输出 N 次。驻留更久所以更亮，**代价是 N 倍的点**。乘出来超过内部上限时这个操作会被整体跳过（没有提示） |
| **Anchors** | 每 N 个点留一个亮点、其余灭掉。**把实线变成一排光束** |
| **Anchor Count** | 不管内容多长，整帧归成**恰好 N 束**等距光束 |
| **Beat Dots** | 在整层点流上等间距取 N 个位置，每处驻留若干采样，其余全丢。**把图形变成光束秀** |

两个共用参数：

| 参数 | 默认 | 范围 | 说明 |
| --- | ---: | --- | --- |
| **Count** | 8 | 1–256 | 随操作而变：重复倍数 / 间隔 / 光束数 |
| **Brightness** | 1.0 | 0–1 | 施加在这个操作保留下来的那些点上。**Beat Dots 例外**——那里它决定每束驻留几个采样（约 2–24 个），颜色原样保留 |

> 点级操作花的是**点预算**。重复点会让同一段弧占用更多采样，帧率随之下降——记得回头看扫描仪面板给出的帧率判词。

---

## 8. Filter（清理）

这一类**不产生动画**，只改这一帧怎么画出来。

| 操作 | 说明 |
| --- | --- |
| **Even Spacing** | 沿路径重采样成等间距。**等间距就是等亮度** |
| **Reduce Points** | 抽稀。用路径变粗糙换帧率 |
| **Soft Line Ends** | 每条可见笔迹的首尾点淡出，线头不再爆亮 |
| **Trim Blanking** | 把过长的空跑并成一次移动。**收回那些花在横穿画面上的采样** |
| **Smooth Path** | 每个点与邻点取平均，抹掉路径抖动。描出来的 logo 和老 ILDA 素材满是台阶，振镜得跟着抖——平滑它**不花点数**，还给振镜减负 |

共用参数 **Amount**（默认 4.0，范围 0–64）随操作而变：

| 操作 | Amount 的含义 |
| --- | --- |
| Even Spacing | **点数倍率**。默认 4.0 表示重采样成原来 4 倍的点数 |
| Reduce Points | 抽稀倍数 |
| Soft Line Ends | 淡出长度 |
| Smooth Path | 平滑遍数（1–8） |
| Trim Blanking | 空跑长度阈值（2–64 个采样），超过就并成一次移动 |

---

## 9. Device Chase（设备轮播）

内容在多台激光设备之间走位。一个动画驱动全场激光时，靠它做跑马灯、左右互答、逐台点亮。

| 参数 | 默认 | 范围 | 说明 |
| --- | ---: | --- | --- |
| **Steps** | 空 | — | 一步一个位置，每步写明这一刻点亮哪几台设备（1 基）。**留空的步就是暗的**——这是做出轮播间隙的办法 |
| **Fade** | 0 | 0–0.5 | 每一步用于淡入淡出的比例。0 是硬切 |

`Fade` 调大之后内容在设备之间是**交接**而不是跳变，扫过整排激光才像一次连续运动。

> **淡入淡出要花帧率**：正在淡出的那一层照样占点预算，两台设备重叠期间帧率会掉一点。硬切不花钱。

---

## 10. 参数露出规则

**Scope（作用范围）与 Strength 只出现在真正用得到的效果上**，不再对所有效果一律露出。每个效果有自己的中心点；效果链会显示摘要，不用逐个展开看。
