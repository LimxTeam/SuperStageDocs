# 激光总览

> 适用版本：SuperStage 26H2.6 起

SuperStage 的激光能力分三层，用途不同、入口不同：

| 层 | 是什么 | 适用场合 |
| --- | --- | --- |
| **激光图案对象** | 场上一支 16 通道 DMX 激光灯，跑 30 种内置矢量图案 | 想让控台像控普通灯一样控激光 |
| **激光动画资产** | 在内容浏览器里创作的矢量激光内容，可编辑、可烘焙、可进 Sequencer | 要做具体的激光节目内容 |
| **外部点云接入** | 接收专业激光控制软件送来的网络点云 | 内容在外部软件里做，UE 只负责呈现 |

---

## 1. 激光图案对象

场景对象 **LaserPattern**，资产浏览器的 SuperStage 分类下。

- **30 种程序化矢量图案**：几何、波形、曲线、数字等，含 Blackout；
- **16 通道 DMX 控制**：图案选择、尺寸、位置、旋转、颜色、点密度，以及 Ch16 的位域——

  | 位 | 功能 |
  | --- | --- |
  | Bit0–1 | 镜像（X / Y） |
  | Bit2–4 | 7 种全局运动：Sweep / Pulse / Orbit / Figure-8 / Spin Pulse / Drift / Bloom |
  | Bit5–6 | 颜色动画：Rainbow / Spectrum / Fire / Cycle |

- 也可以脱离 DMX 以属性模式运行内置动画。

Ch5/Ch6 的位置映射以 128 为中位，两侧斜率略有不同（负向 /128、正向 /127）；Ch8 恰好 128 时旋转停止，两侧分别是两个方向。

## 2. 激光动画资产（26H2.6 新增）

在内容浏览器创建、双击打开。配套画布编辑器、SVG 导入器、烘焙器与 Sequencer 轨道。

两个设计前提值得先知道：

**存矢量不存点云。** 资产里存的是贝塞尔轮廓与调制参数，点流在播放时现算。所以它分辨率无关、随时可回改，换扫描仪参数不必重做内容。

**没有固定时长。** 运动来自效果的频率，不同效果的周期互不相关。任意时刻可以直接求值，拖动、跳转、倒放都不需要预热。

## 3. 外部点云接入

场景对象 **LaserPro**，接收外部专业激光控制软件输出的网络点云数据（UDP 多播）。

| 项 | 当前值 |
| --- | --- |
| 设备位 | 默认 60 台 |
| 组播地址 | `239.255.{设备号}.{子网号}` |
| 加组操作 | 在接收线程完成 |

呈现能力：

- **HotBeam 光束驻留增强**：驻留光束点渲染为等宽光束柱，带高斯亮芯与专属增益，任意视角可见；
- **ILDA 笔迹语义连线**：空白点抬笔、同位置驻留点折叠、跨图形跳变自动断开；
- **表面命中**：连线图形打在墙面 / 地面上显示为贴面线条（需开启碰撞检测）；命中点渲染为面向相机的辉光光点；
- **扇面**：带笔迹明暗（慢速段与角点更亮）、世界空间烟雾与散射相位调制；
- **扫描仪仿真**默认关闭——它的插值与惯性平滑会破坏 HotBeam 的驻留语义，需要时可在设置里开启；
- **镜像开关** MirrorX / MirrorY 通过渲染网格缩放实现，不改动激光点数据；
- **点云压缩录制**与 Sequencer 回放（配合 Take Recorder）。

具体支持的第三方激光软件及版本，以官方网站与文档中心的说明为准。

## 4. 控制权仲裁

一台激光设备可能同时被三个来源写：外部网络点云、激光编辑器预览、Sequencer 激光轨。子系统按设备逐台仲裁，不是全局开关。

| 优先级 | 来源 | 什么时候写 |
| --- | --- | --- |
| 高 | **Sequencer** | 时间轴上有激光轨且在播 |
| 中 | **Editor Preview** | 激光编辑器窗口打开且在预览 |
| 低 | **Network** | 外部激光软件的实时点云 |

规则：

- 无人占用时，谁都能写；
- 写入时占住该设备，**同级或更高优先级**的来源才抢得走；
- 只有占用者本人能释放，低优先级来源退不掉别人的占用；
- 仲裁只看优先级，不做混合——抢到的源完整接管这台设备的画面。

**超时自动释放**：占用者连续 **1 秒**没有写入，设备视为已释放。这是异常兜底：Sequencer 被强停、编辑器窗口被杀时不会走正常的释放流程，没有这条，设备就永远归它、网络流再也回不来。

> 网络点云推了但设备不亮，先看这台是不是被 Sequencer 或预览占着。关掉时间轴播放、关掉预览窗口，或等一秒超时，网络流会自己回来。

## 5. 安全边界

**SuperLaser 用于视觉预演、内容创作与数据可视化，呈现的是激光节目的画面表达，不是真实激光输出控制。**

它不提供：观众区扫描许可、最大允许照射量（MPE）计算、激光分区认证、物理投影仪校准、急停硬件、扫描失效保护，也不构成法规审批依据。

任何真实激光系统的使用，仍须由具备资质的激光操作人员、经认证的硬件、场地规则和当地法规约束。**导出的 ILDA 文件在送入真实激光系统之前，必须由持证操作人员按现场安全规程复核。**
