# 激光动画资产

> 适用版本：SuperStage 26H2.6 起 ｜ 前置阅读：[激光总览](00_Laser_Overview_zh.md)

激光动画资产是 26H2.6 新增的激光内容创作载体。在内容浏览器右键创建，双击打开编辑器。

---

## 1. 两个设计前提

### 存矢量，不存点云

资产里存的是**贝塞尔轮廓与调制参数**，点流在播放时现算。带来三件事：

- **分辨率无关**——同一份内容在 20 kpps 和 40 kpps 的扫描仪上都对；
- **随时可回改**——不是烘死的点，改一个控制点整条内容跟着变；
- **换扫描仪参数不必重做内容**。

### 没有固定时长

运动来自效果的**频率**，不同效果的周期互不相关。任意时刻可以直接求值，所以拖动、跳转、倒放都不需要预热，也不存在"这段动画有多长"这个问题。

---

## 2. 资产结构

```text
激光动画资产
 ├── Tempo                节拍 BPM，默认 120（20~300）。效果按拍走时的基准
 ├── Scan Profile         扫描仪规格（见第 4 节）
 ├── Preview Device IDs   预览推给哪几台设备（1 基，对应设备的 DeviceID）
 ├── Device Time Shift    设备间时间偏移，秒（−5~5）
 ├── Export Frame Count   导出帧数，默认 1（1~9999）
 ├── Export Frame Rate    导出帧率，默认 30（1~120）
 ├── Export Device ID     导出哪一台设备的画面，0 = 全部图层不管路由
 └── Layers[]             图层栈，**下标 0 在最底层**
      ├── 内容源（六选一）
      ├── Transform / Color / ScanMode
      └── Effects[]       效果栈，按顺序求值
```

**坐标一律在扫描仪归一化空间 `[-1, 1]`，Y 向下为正**（与 UE 屏幕系一致）。

**图层只有一级，不能嵌套。** 两级会让变换、颜色、效果链各出两份，界面上也要两套增删按钮，分不清该点哪一套。

> **导出设置为什么存在资产里**：资产没有总时长（每个效果各自循环），"导出多长"从内容里推不出来，推出来的一定是错的，只能由人显式决定。导出对话框以这几个值起手，确认后写回来，下次导出接着用。

## 3. 图层

### 3.1 内容来源

每个图层的内容来自六类之一：

| 来源 | 说明 |
| --- | --- |
| **Path** | 手绘 / 编辑的贝塞尔路径 |
| **Primitive** | 内置图元，16 种：Circle、Ellipse、Rectangle、Polygon、Star、Line、Arc、Spiral、Lissajous、Wave、Grid、Cross、Heart、Rose、Beam Dot、Beam Fan |
| **Text** | 文字。由字体轮廓直接取贝塞尔曲线，不经位图 |
| **Imported** | 导入的矢量（SVG） |
| **Mesh** | 从网格取轮廓 |
| **ILDA Sequence** | 导入的 ILDA 帧序列 |

### 3.2 扫描模式（Scan Mode）

**这是图层上最容易被忽略、却决定观感的一项。** 它是**内容选择**——这一层要画成线，还是停成一束束光——不是扫描仪的物理参数，所以在图层上而不在扫描仪规格里。

| 模式 | 含义 |
| --- | --- |
| **Line** | 线条。默认 |
| **Beam** | 光束。沿路径**等弧长**取出若干束，每束停驻若干采样 |
| **Hybrid** | 混合 |

`Beam` 与 `Hybrid` 下面两个参数才起作用：

| 参数 | 默认 | 范围 | 说明 |
| --- | ---: | --- | --- |
| **Beam Count** | 12 | 1–64 | 沿路径取几束 |
| **Beam Dwell** | 8 | 1–60 | 每束停驻几个采样。**当前烘焙器对每束固定用 8 个采样，改这个值不会改变烘出来的结果** |

> 注意这与内容源里的 `Beam Dot` / `Beam Fan` 两个图元**是两回事**：那两个是形状，这里是扫描方式。任何形状都可以切到光束模式。

### 3.3 其它图层参数

| 参数 | 默认 | 范围 | 说明 |
| --- | ---: | --- | --- |
| **Name** | `Layer` | — | 图层名 |
| **Visible** | 开 | — | 是否参与求值 |
| **Locked** | 关 | — | 锁定后节点工具不再改它的路径，方向键微调也跳过它。**用 Select 工具仍然能点中并拖动**，锁的是路径不是位置 |
| **Curve Detail** | 256 | 4–256 | 曲线细分成多少直段。**只影响真正含曲线的内容**——文字、带圆角的形状、导入的矢量图。调低省点，太低圆弧会看出折线 |
| **Transform** | — | — | 见 3.4 |
| **Color** | — | — | 图层底色，纯色。真正的上色变化交给颜色效果 |
| **Effects** | 空 | — | 效果栈，按顺序求值，见[效果系统](03_Effects_zh.md) |

图层可跨资产复制粘贴——剪贴板走 Base64 编码，多行文字图层不会被切成两半。

### 3.4 变换（Transform）

应用顺序与 Illustrator 一致：**缩放 → 斜切 → 旋转 → 平移**。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| **Location** | (0, 0) | 平移 |
| **Rotation** | 0 | 度。**正值顺时针**（屏幕系 Y 向下，视觉上与 Illustrator 一致） |
| **Scale** | (1, 1) | 缩放 |
| **Shear** | (0, 0) | 度。X 斜切 / Y 斜切 |
| **Pivot** | (0, 0) | 旋转与缩放的锚点，图形本地空间 |

> 缩放为零、或斜切退化时变换不可逆，画布上拖节点会失效——那是数学上算不回去，不是 bug。

### 3.5 图元参数（Primitive）

`Param A` / `Param B` 的含义**随图元类型而变**，界面会按类型改标签：

| 图元 | Param A | Param B |
| --- | --- | --- |
| Polygon | 边数（3~64） | — |
| Star | 角数（3~32） | 内径比（0~1） |
| Rectangle | 圆角（0~1，钳到 1 就成了胶囊） | — |
| Arc | 起始角（度） | 张角（度） |
| Spiral | 圈数 | 内径比 |
| Lissajous | X 频率 | Y 频率 |
| Wave | 周期数 | 振幅 |
| Grid | 列数 | 行数 |
| Rose | k 值 | 未用 |
| Beam Fan | 光束数（1~64） | 张角（度） |

另外两项：**Size**（默认 0.5 × 0.5）与 **Resolution**（生成轮廓的采样密度，**0 = 按点距自动算**，上限 2048）。

> **换图元类型时 Param A / B 会自动套用该类型的合理默认值。** 因为同一个数字在不同类型下含义完全不同——5 对星形是"五角"，对矩形却是圆角比例、钳到 1.0 就成了胶囊。自己调过的值在类型没变时不会被动。

### 3.6 文字参数（Text）

| 参数 | 默认 | 范围 | 说明 |
| --- | ---: | --- | --- |
| **Text** | `LASER` | — | 文字内容 |
| **Font** | 空 | — | 字体资产。留空用工程默认字体 |
| **Size** | 0.4 | 0.01–2.0 | 字号，归一化空间高度 |
| **Tracking** | 0 | −0.5–2.0 | 字距，占字号比例 |
| **Line Height** | 1.2 | 0.1–4.0 | 行距，占字号比例 |
| **Align** | Center | — | Left / Center / Right |

## 4. 扫描仪规格（Scan Profile）

**点预算是核心**：一帧就这么多采样，所有内容按弧长分它。

| 参数 | 默认值 | 范围 | 说明 |
| --- | ---: | --- | --- |
| Point Count | 600 | 24–6000 | 每帧采样数。这是预算，效果链里的点重复 / 镜像也从这里花 |
| Point Rate | 30 kpps | 5–80 | 采样时钟，千点每秒 |
| Corner Dwell | 4 | 0–16 | 尖角处重复的采样数，按 角度/90 缩放。不留则转角被画圆——振镜有质量，不能瞬间转向 |
| Blank Lead In | 3 | 0–24 | 跳转前先灭光的采样数 |
| Blank Lead Out | 4 | 0–24 | 跳转后等振镜稳定再点亮的采样数 |
| Color Shift | 0 | −12–12 | RGB 相对 XY 的采样偏移，补偿调制滞后造成的拖色 |
| Optimize Path Order | 开 | — | 重排笔迹顺序以缩短空跑。**空跑也花采样**，排得不好帧率就塌 |

> **帧率不是设定值，是推导量**：`帧率 = 点率 ÷ 点数`。低于约 22 Hz 快速运动会看出闪，低于 15 Hz 就是明显闪烁。界面会直接给出判词，不用自己算。

---

## 5. 多设备

一个动画可以推给多台设备。

- **Preview Device IDs**：预览时推给哪几台；
- **Device Time Shift**：设备之间的时间偏移，用来做走位错开；
- **Sequencer 逐台烘焙**：每台设备烘一条。

---

## 6. 走带

画布下面那一条是**走带栏**，不是时间轴：播放 / 暂停、停止回到起点、一个自由运行的时钟读数，加上工具、设备下拉、帧率与 Grid / Snap / Blanking / Points 几个显示开关。

**它没有滑杆，也没有时间轴。** 因为这类内容本来就没有"总时长"：每个效果按自己的周期跑，各周期之间互不相关，拖一条从 0 到"结尾"的进度条没有意义。想让内容按秒精确排，用 Sequencer——见下一节。

---

## 7. 在场景里使用

1. 场景中放置激光设备对象；
2. 在设备上引用这份动画资产；
3. 或者在 Sequencer 里加激光轨道，按设备烘焙。
