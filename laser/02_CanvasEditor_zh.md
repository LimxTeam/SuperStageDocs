# 激光画布编辑器

> 适用版本：SuperStage 26H2.6 起 ｜ 前置阅读：[激光动画资产](01_LaserAnimationAsset_zh.md)

双击激光动画资产打开编辑器。

---

## 1. 界面构成

| 位置 | 页签 | 内容 |
| --- | --- | --- |
| 左侧约 20% | **Layers** | 图层列表：增删、排序、显隐、锁定 |
| 中间约 52% | **Canvas** | 画布 |
| 右侧约 30%（默认显示 Layer） | **Layer** | 当前图层的形状参数 |
| | **Effects** | 效果栈 |
| | **Details** | **整资产级设置**：扫描仪规格、Tempo、预览设备、导出设置 |

日常调形状在 **Layer** 页；**扫描仪规格与预览设备在 Details 页**——这是找不到点数、点率设置时该去的地方。

画布下面那一条是**走带栏**（播放 / 停止 / 时钟读数 / 工具 / 设备下拉 / 帧率 / 显示开关），不是时间轴——它没有滑杆，见 [动画资产](01_LaserAnimationAsset_zh.md) 第 6 节。

---

## 2. 三个工具

画布顶部三个工具按钮，各带快捷键（与 Illustrator / Photoshop 一致）：

| 工具 | 快捷键 | 作用 |
| --- | --- | --- |
| **Select** | `V` | 选图层、拖图层 |
| **Nodes** | `A` | 拖路径节点与控制柄 |
| **Pen** | `P` | 点击落点画路径 |

另有 `F` **回到默认视图**。

---

## 3. 画布操作

| 操作 | 说明 |
| --- | --- |
| **中键拖动** | 平移画布 |
| 滚轮 | 缩放 |
| `F` | 重置视图（缩放回 1、平移归零，适配窗口） |

走带栏上的设备下拉可以选 **All Devices**（忽略设备路由、画出全部图层）或某一台，用来看这台设备实际会投出什么。它**只在预览设备多于一台、或内容里有按设备轮播的效果时才出现**。

> 画布画的是扫描场本身（恒定 `[-1, 1]` 的方形），不画某台设备在现场的投射范围。

---

## 4. Select 工具

| 操作 | 说明 |
| --- | --- |
| 点击 | 选中图层 |
| **Ctrl / Shift 点击** | 加选，与内容浏览器、大纲一致 |
| 拖动 | 移动选中的图层 |
| 变换手柄 | 四角自由缩放；**边中点的手柄只缩一个方向** |
| **Shift + 拖角手柄** | 等比缩放，图形不变形 |

> 点中一个**已经选中**的图层不会清掉其它选中项——否则多选之后想整体拖动，一按下去就只剩这一个了。

---

## 5. Nodes 工具（节点级编辑）

图层内容是三次贝塞尔曲线，控制柄以"相对节点的偏移"存储，拖节点时手柄跟着走。

| 操作 | 说明 |
| --- | --- |
| 拖节点 | 改形状 |
| 拖控制柄 | 改曲率。默认两侧手柄**对称联动** |
| **Alt + 拖控制柄** | **断开对称**，两侧手柄各走各的 |
| **Ctrl + 点击空白处** | **在最近的线段上插入一个节点** |
| 空白处拖动 | 框选 |
| **Ctrl + A** | 全选当前图层的节点 |
| **C** | **切换尖角标记**（见第 6 节） |
| **Delete** / **Backspace** | 删除选中节点 |

**删多个节点合并为一次撤销**。换图层时会清掉跟下标绑定的编辑状态，不会串到新图层上。

> **Alt 只断开手柄对称，不改尖角标记。** 两件事混在一起的话，按住 Alt 拖手柄会把这点设成尖角，而尖角是屏蔽手柄的——于是拖了半天手柄毫无反应。

---

## 6. Pen 工具

点击逐个落点画路径。**`Esc` 收笔**——画到一半想另起一条时用，不然会一直往同一条轮廓上接。

---

## 7. 尖角标记

节点上的尖角标记**不是装饰**，它实际影响烘焙：标为尖角的节点会在烘焙时分配驻留采样，让振镜有时间转向。不标的节点会被当成平滑过渡，转角会被画圆。

---

## 8. 文字图层

文字由**字体轮廓直接取贝塞尔曲线**，中间不经位图。所以：

- 缩放不糊；
- 可以转成路径后逐点编辑；
- 点预算按字形轮廓的弧长分配，不是按像素。

多行文字图层跨资产复制粘贴时不会被切成两半（剪贴板走 Base64 编码）。

---

## 9. 图层面板与工具栏

**Layers 页**：图层列表，可增删、排序、显隐、锁定。**图层可跨资产复制粘贴**（剪贴板走 Base64，多行文字不会被切断）。

**主工具栏**只有三个按钮：

| 按钮 | 作用 |
| --- | --- |
| **SVG** | 导入 SVG / Illustrator 路径为新图层。**直接读文件里的矢量数据，不往工程里导入任何资产** |
| **Import ILDA** | 读 `.ild` 文件。**单帧变成可编辑图形；动画保留每一帧并按自己的速率循环** |
| **Export ILDA** | 烘焙成 `.ild`。会先问导出几帧——**这份资产没有自己的长度**，一帧是静止图，多帧才是动画 |

**Add Layer** 在图层列表的工具栏上；**To Path**（把图元 / 文字转成可逐点编辑的路径）与设备下拉在画布下面的走带栏上。

**Add Layer 的五组**：

| 组 | 内容 |
| --- | --- |
| **Import** | SVG、ILDA、Trace 3D Mesh |
| **Basic** | Circle、Ellipse、Rectangle、Polygon、Star、Line、Arc、Cross |
| **Curves** | Spiral、Lissajous、Wave、Rose Curve、Heart、Grid |
| **Beams** | Single Beam、Beam Fan |
| **Text** | 由字体轮廓生成，改字符串即刻重生成 |

**Trace 3D Mesh** 按一个**可以继续转**的视角描出静态网格的轮廓；内容浏览器里选中了网格就用那个。

> 菜单上的名字与图元枚举名略有出入：`Rose Curve` 对应 Rose，`Single Beam` 对应 Beam Dot。

---

## 10. 曲线细分

图层的 Curve Detail（4–256）控制曲线细分度，改动会真正反映到求值结果上。细分越高形状越准，占的点预算也越多。

---

## 11. 走带栏

走带栏**可换行**：画布窄的时候控件会折到下一行，不会被挤出可视范围。

**导入与导出**在资产编辑器的主工具栏上。
