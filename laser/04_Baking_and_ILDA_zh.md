# 烘焙与 ILDA

> 适用版本：SuperStage 26H2.6 起 ｜ 前置阅读：[激光动画资产](01_LaserAnimationAsset_zh.md)

---

## 1. 烘焙器

烘焙把矢量内容变成扫描仪能吃的点流。它遵守振镜物理，不是简单按弧长撒点。

| 环节 | 做法 |
| --- | --- |
| 点数预算 | 所有图层按弧长分 Point Count 那个数。**尖角驻留、点重复与光束驻留是在这之外追加的**，所以实际点数会略高于预算 |
| 尖角驻留 | 按尖角严重程度分配驻留采样（按 角度/90 缩放） |
| 消隐补驻留 | 跳转前先灭光若干采样（Blank Lead In），跳转后等振镜稳定再点亮（Blank Lead Out） |
| 顺序优化 | 减少空程 |
| 颜色去斜 | 补偿颜色通道相对位置通道的延迟（Color Shift） |

**帧率是推导结果**：`帧率 = 点率 ÷ 点数`。界面直接给出判词，不用自己算：

- 低于约 22 Hz，快速运动会看出闪；
- 低于 15 Hz，就是明显闪烁。

想提高帧率，要么减少内容、要么减少点级操作（重复点很花预算）、要么提高点率——但点率上限取决于真实扫描仪的规格。

---

## 2. 预演一致性

**自制内容与烘焙内容走同一条处理链**，所以预演里两条来源看起来是一致的。链上的扫描仪模拟本身默认关闭，需要时在扫描仪设置里打开。

---

## 3. Sequencer

激光动画可以在 Sequencer 里逐台设备烘焙，与 UE 时间轴内容（摄像机、动画、音频）共同编排。

---

## 4. ILDA

ILDA（IDTF）是激光行业**唯一通用的帧交换格式**。不支持它就意味着既用不了任何已有素材库，做出来的东西也交付不到别人的控台上。

实现按 **IDTF14 rev011** 规范。

### 4.1 支持的格式号

| 格式 | 含义 |
| ---: | --- |
| **0** | 3D 索引色 |
| **1** | 2D 索引色 |
| **2** | 调色板 |
| **4** | 3D 真彩 |
| **5** | 2D 真彩 |

**遇到未知格式的段，导入就到此为止**：记录大小未知就没法跳过它，继续往下读只会把后面全部读错。已经读出来的帧保留，导入报告会说明在第几帧停下、遇到的是哪个格式号。

### 4.2 读

导入的帧序列可以作为图层内容源（`ILDA Sequence`）：**单帧变成可编辑图形，动画保留每一帧并按自己的速率循环**。

段头里的**名字与作者**会原样带进来，方便溯源。

**索引色的调色板**：文件自带 Format 2 段就用文件里的；没带才退回默认表。默认表只覆盖规范附录里那批饱和色——**覆盖不到的索引会如实报出来，不会静默给个白色蒙混过去**。

导入报告给出：读到几帧、几个点、**没解出调色板的点数**、跳过的未知格式段数。

### 4.3 写

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| **Frames** | 1 | 烘几帧。**资产没有总时长，只能显式决定**——1 帧是静止图，多帧才是动画 |
| **Frame Rate** | 30 fps | 相邻两帧的时间步由它换算。只烘 1 帧时不用 |
| **Start At** | 走带当前时刻 | 从哪个时刻开始烘 |
| **Device** | 不区分 | 按哪台设备的视角导出 |
| **Format** | 2D | 2D 写格式 5，3D 写格式 4 |

对话框里还有两样：**Fit to Loop** 按钮，按内容的周期自动定帧数；以及一句循环判词，告诉你这批帧是**精确循环**、**各周期无公倍数**还是**不重复**。

段头里的名字取资产名（截断到 8 字节），公司名固定写 `SUPRSTGE`。文件结尾按规范写一个**记录数为 0 的段头**。

导入与导出入口在资产编辑器的主工具栏上。

### 4.4 与其它软件对接时值得核对的三项

导出的文件按 IDTF14 rev011 规范写。和第三方软件对接出问题时，先核这三项——它们是不同实现之间最容易分歧的地方：

| 项 | 规范怎么定 |
| --- | --- |
| **字节序** | 32 字节段头，多字节字段一律**大端** |
| **Y 轴方向** | X 右为正、**Y 上为正** |
| **真彩颜色字节序** | **B, G, R**，不是 R, G, B |

状态字节：bit6 = 消隐（1 = 激光关），bit7 = 最后一点。

## 5. 安全提醒

**导出的 ILDA 文件在送入真实激光系统之前，必须由持证操作人员按现场安全规程复核。**

本产品不提供观众区扫描许可、最大允许照射量（MPE）计算、激光分区认证、物理投影仪校准、急停硬件或扫描失效保护，也不构成法规审批依据。
